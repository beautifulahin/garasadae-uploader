# 가라사대 업로더

**영상을 채널 폴더에 넣고, 화면에서 골라 담아 올리면 유튜브에 올려 줍니다.**
**채널을 여러 개 운영하신다면 채널마다 폴더를 하나씩 두고 각각 올릴 수 있습니다. 쇼츠와 롱폼은 알아서 가려 줍니다.**

> ### 💬 의견을 들려주세요
> 쓰시면서 불편했던 점, 있었으면 하는 기능, 오류를 알려주시면 하나하나 읽고 반영합니다.
>
> | | |
> |---|---|
> | 🐞 **[오류가 나요](https://github.com/beautifulahin/garasadae-uploader/issues/new?template=1_bug.yml)** | 프로그램이 제대로 동작하지 않을 때 |
> | 💡 **[이런 게 있었으면](https://github.com/beautifulahin/garasadae-uploader/issues/new?template=2_idea.yml)** | 필요한 기능을 알려주세요 |
> | 📋 **[접수된 의견 보기](https://github.com/beautifulahin/garasadae-uploader/issues)** | 다른 분들이 남긴 의견과 처리 상황 |
>
> 프로그램의 **💬 의견 보내기** 탭에서 보내시면 환경 정보가 자동으로 채워집니다.

영상 만들고 나서 유튜브 열고, 업로드 누르고, 제목 넣고, 기다리는 일을 안 해도 됩니다.
폴더에 넣고 **담기 → 올리기** 만 누르면 비공개로 올라가고, 30분 뒤 심사 결과를 보고 알아서 공개합니다.

- 맥 · 윈도우 모두 됩니다
- 설치할 것 없습니다. 받아서 실행만 하면 됩니다
- 구글 로그인 열쇠가 들어 있어 **구글 클라우드 설정 없이 로그인만 하면** 됩니다 (2.0.0 부터)
- 영상에 맞는 **제목·설명·해시태그 자동 작성**(AI)과 **쿠팡 파트너스 상품 링크 자동 넣기**는 선택이고, 열쇠는 각자 자기 것입니다
- 무료입니다

## 1. 설치하기

### 🍎 맥 — 한 줄 설치 (가장 쉽고, 경고창이 안 뜹니다)

**응용 프로그램 → 유틸리티 → 터미널** 을 열고, 아래 한 줄을 붙여넣고 Enter 를 누르세요.

```
curl -fsSL https://beautifulahin.github.io/garasadae-uploader/install.sh | bash
```

받기 · 설치 · 실행까지 알아서 다 합니다. 1분이면 끝나고, 브라우저에 화면이 열립니다.
내 맥이 Apple 칩인지 Intel 칩인지도 알아서 가려 받습니다.

> **왜 터미널인가요?**
> 브라우저로 받으면 맥이 「인터넷에서 받음」 표를 붙여서 보안 경고가 뜹니다.
> 터미널로 받으면 그 표가 안 붙어서 **경고창 자체가 나오지 않습니다.**

### 🪟 윈도우 · 🍎 맥 (직접 받기)

**[⬇️ 여기서 받으세요](https://github.com/beautifulahin/garasadae-uploader/releases/latest)**

| 내 컴퓨터 | 받을 파일 |
|---|---|
| 윈도우 10 / 11 | `garasadae-uploader-windows.zip` |
| 맥 (Apple 칩) | `garasadae-uploader-mac-apple-silicon.zip` |
| 맥 (Intel 칩) | `garasadae-uploader-mac-intel.zip` |

> **내 맥이 어느 쪽인지 모르겠다면**
> 왼쪽 위 사과 모양 → **이 Mac에 관하여** → **칩** 항목을 보세요.
> `Apple` 로 시작하면 Apple 칩, `Intel` 이면 Intel 입니다. 요즘 맥은 대부분 Apple 칩입니다.

## 2. 실행하기

**윈도우** — 압축을 풀고 실행한 뒤, 파란 경고창의 **추가 정보** → **실행**

**맥** — 위의 **한 줄 설치**로 하셨다면 이미 실행까지 끝났습니다. 아래는 zip 을 직접 받으신 경우입니다.

<details>
<summary><b>맥에서 zip 을 직접 받으신 경우 — 처음 한 번만 이렇게 엽니다</b></summary>

**① 열기.command 를 더블클릭** — 압축 안에 같이 들어 있습니다. 아래 과정을 대신해 줍니다.

**② 손으로 하기 (macOS 15 이상 · 요즘 맥은 대부분 여기)**

1. 앱을 **응용 프로그램** 폴더로 옮깁니다.
2. 한 번 더블클릭합니다. **「열지 않음」** 창이 뜨면 **[완료]** 를 누릅니다.
   > ⚠️ **[휴지통으로 이동] 은 절대 누르지 마세요.** 앱이 지워집니다.
3. **시스템 설정 → 개인정보 보호 및 보안** 을 열고 아래로 내립니다.
   *「'가라사대 업로더'이(가) 차단되었습니다」* 옆의 **[무시하고 열기]** 를 누르고 암호를 넣습니다.
4. 다음부터는 그냥 더블클릭하면 열립니다.

**③ 옛 맥 (macOS 14 이하)** — 아이콘에 **오른쪽 클릭 → 열기** → 경고창에서 다시 **열기**.

</details>

인증 비용을 들이지 않은 개인 배포 프로그램이라 나오는 안내입니다. 프로그램에 이상이 있는 것이 아닙니다.
번거로우시면 맨 위의 **한 줄 설치**를 쓰시면 경고창을 아예 안 보십니다.

## 3. 구글 계정 연결하기 (로그인 한 번)

실행하면 브라우저에 화면이 열립니다. **📺 채널** 탭(또는 **🚀 시작하기** 탭)에서 **🔑 구글 계정 연결** 을 누르고,
유튜브 채널이 있는 계정으로 로그인하세요. 한 계정에 채널이 여럿이면 계정 선택 창에서 바꿔 가며 잇달아 연결할 수 있습니다.

> 📖 **[자세한 설정 안내서](docs/설정안내.md)** — 화면을 보면서 따라 하실 수 있게 단계별로 정리해 두었습니다.
> 내 구글 열쇠를 직접 만들어 쓰고 싶다면 안내서의 **[부록 A](docs/설정안내.md#부록-a--내-구글-열쇠를-직접-만들어-쓰기-선택)** 를 보세요.
> 막히는 곳이 있으면 안내서 맨 아래 **막혔을 때** 를 보세요.

처음 켜면 **AI·쿠팡 파트너스 열쇠 창**이 한 번 뜹니다. 이 컴퓨터에 이미 있는 열쇠를 찾아서 보여 주고, 시험을 통과한 것을 한 번 눌러 연결합니다. 지금 안 넣어도 됩니다.

## 4. 쓰기

영상을 채널 폴더(기본: 홈 폴더의 `가라사대업로더영상/채널이름/`)에 넣으면 **👀 감시 중** 탭에 카드로 나옵니다.
**담기 → 올리기** 를 누르면 확인 창에서 제목·설명·올리는 시각을 보고 올립니다. 화면에 **끌어다 놓아도** 됩니다.

터미널에서는 `GarasadaeUploader 도움말` 로 한글 명령을 볼 수 있습니다.

> **1.x 에서 자동으로 올라오셨나요?** 등록해 둔 채널·로그인·기록은 하나도 없어지지 않습니다.
> 처음 켤 때 복사본을 먼저 떠 두고 옮긴 뒤 하나씩 확인합니다 — 자세한 내용은 [안내서](docs/설정안내.md#옛-버전에서-올라오신-분께)에.

## 5. 인스타그램 릴스·스레드에도 올리기 (선택)

유튜브에 올린 **쇼츠**가 공개되는 때에 맞춰 같은 영상을 **인스타그램 릴스**와 **스레드**에도 자동으로 올립니다. 쓰지 않으면 아무것도 달라지지 않습니다 (기본은 꺼짐).

1. **사용 신청** — 이 기능은 **신청한 분만** 쓸 수 있습니다. 인스타그램 아이디(스레드도 쓰면 함께)를 **beautifulahin@gmail.com** 으로 메일로 보내 주세요. 설정 탭의 *✉ 신청 메일 쓰기* 단추를 누르면 제목(「가라사대 업로더 인스타·스레드 사용 신청」)과 아이디 칸이 적힌 메일이 열립니다.
2. **초대 수락** — 신청이 받아지면 초대가 옵니다. 인스타그램은 instagram.com › 설정 › 앱 및 웹사이트 › 「테스터 초대」에서, 스레드는 스레드 앱 › 설정 › 설정 더 보기(또는 계정) › 웹사이트 권한 › 초대에서 수락합니다. 수락을 하지 않으면 연결되지 않습니다.
3. **설정 탭 → 📷 인스타그램·스레드**에서 *인스타그램 연결* / *스레드 연결*을 누르고 로그인합니다. 로그인 창만 열리고, 열쇠나 비밀번호를 이 프로그램에 입력하지 않습니다.
4. 같은 카드의 **채널마다 올릴 계정**에서, 올릴 채널에만 계정을 고릅니다 (고르지 않은 채널은 올리지 않습니다).
5. 영상 하나만 켜거나 끄고 싶으면 영상 옆 쪽지(`.json`)에 `"instagram": true` · `"threads": false` 처럼 적습니다. 쪽지가 채널 설정보다 먼저입니다.

문안은 유튜브 문안에서 만들어 줍니다 — 인스타그램은 제목 + 설명 + 해시태그(2,200자·태그 30개까지), 스레드는 제목 + 짧은 설명(500자까지)입니다.

> **알아 두세요**
> - **인스타그램은 비즈니스 또는 크리에이터 계정**이어야 합니다 (개인 계정은 올리기를 지원하지 않습니다. 인스타그램 앱에서 무료로 바꿀 수 있습니다).
> - 이 기능은 메타(인스타그램·스레드) 앱을 심사 없이 개발 모드로 운영하기 때문에 **사용 신청을 하고 초대를 수락한 계정만** 연결됩니다. 신청하지 않았거나 수락하지 않은 계정으로 로그인하면 연결되지 않고, 설정 화면에 신청 방법과 수락하는 곳이 안내됩니다 (직접 취소하신 경우는 「연결을 취소했습니다」로 따로 나옵니다).
> - **세로 쇼츠만** 올립니다. 롱폼·가로 영상, 길이가 릴스 규격(3초~15분)에 맞지 않는 영상은 건너뛰고 그 까닭을 기록해 둡니다.
> - **큰 영상(4K 등)은 자동으로 줄여서 올립니다** — 용량·크기·프레임·코덱만 규격에 안 맞으면 1080×1920 이하로 줄인 사본을 만들어 올리고 원본은 그대로 둡니다. 이때 **ffmpeg 가 설치되어 있어야** 하며, 없으면 건너뛰고 그 까닭을 기록합니다.
> - 올리다 실패해도 **유튜브 쪽에는 아무 영향이 없습니다.** 결과는 같은 카드의 *최근 결과*에서 볼 수 있습니다.
> - 올리는 중에 연결이 끊겨 **올라갔는지 알 수 없는 영상은 같은 영상이 두 번 올라가지 않도록 다시 보내지 않습니다.** 계정에서 직접 확인한 뒤 카드의 *올라갔음 / 안 올라갔음*을 눌러 주세요.
> - 영상은 메타가 가져갈 수 있어야 해서, 올리는 동안(최대 1시간) 로그인 중계 서버에 임시로 두었다가 지웁니다. 자세한 내용은 [개인정보처리방침](docs/privacy.html)에 있습니다.

## 자주 묻는 것

**Q. 돈 드나요?**
전부 무료입니다. 프로그램도, 구글 설정도 요금이 나가지 않습니다.

**Q. 하루에 몇 개까지 올릴 수 있나요?**
구글이 정한 한도 때문에 기본 열쇠로는 **하루 6개 안팎**입니다 (내 열쇠를 쓰면 열쇠마다 따로 받습니다).
넘긴 영상은 사라지지 않고 **다음 날로 자동으로 밀립니다.** 쇼츠·롱폼의 하루 편수와 공개 간격은 채널마다 정할 수 있습니다.

**Q. 올린 영상이 바로 공개되나요?**
아니요. 먼저 **비공개**로 올라가고, **30분 뒤 유튜브의 심사 결과를 확인해** 문제가 없으면 정한 시각에 공개합니다.
공개 시각·간격은 채널마다 정할 수 있고, 위쪽 자물쇠를 잠그면 올리기와 공개가 모두 멈춥니다.

**Q. 편집 프로그램에서 내보내는 중에 폴더에 들어가면요?**
올리기 전에 영상을 읽어 보고(길이·크기·화면 비율), 읽을 수 없는 파일은 올리지 않습니다. 내보내기가 끝난 뒤에 담아 주세요.

**Q. 업로드 중에 인터넷이 끊기면요?**
끊긴 지점부터 이어서 올립니다. 처음부터 다시 올리지 않습니다.

**Q. 창을 닫으면 멈추나요?**
설정에서 **컴퓨터 켤 때 자동 실행** 을 켜두면 창을 닫아도, 컴퓨터를 껐다 켜도 계속 동작합니다.
(로그인 때 화면 서버가 켜지고, 10분마다 심사 결과를 확인해 공개하는 작업이 따로 돕니다.)

**Q. 올린 뒤 원본 파일은 어떻게 되나요?**
채널마다 고를 수 있습니다 — `업로드완료` 폴더로 옮기기 / 휴지통 / 그대로 두기. 이 프로그램은 영상 파일을 **지우지 않고** 휴지통으로 보냅니다(되살릴 수 있게).
어느 쪽이든 **유튜브에 실제로 올라간 것을 확인한 뒤에만** 처리합니다.

**Q. 제 구글 계정 정보가 만든 사람에게 넘어가나요?**
아닙니다. 로그인 정보(토큰)는 본인 컴퓨터에만 저장되고 어디로도 보내지 않습니다.
프로그램에 들어 있는 것은 구글 **로그인 창을 여는 앱 열쇠**뿐이고, 계정 비밀번호나 토큰은 만든 사람이 볼 수 없습니다.
(인스타그램·스레드를 연결하는 선택 기능만, 로그인 때 토큰을 바꿔 주는 중계 서버를 잠깐 거칩니다 — 5분 안에 지워지며 [개인정보처리방침](docs/privacy.html)에 적혀 있습니다.)

**Q. 어떤 권한을 받나요? 유튜브 영상이 지워질 수도 있나요?**
권한은 세 가지입니다 — 영상 올리기(`youtube.upload`) · 유튜브 읽기(`youtube.readonly`: 채널 정보·성적) · 영상 정보 고치기(`youtube`: 비공개 → 공개 전환).
세 번째는 구글이 정한 이름상 계정 관리 범위라 기술적으로는 삭제까지 포함하지만, **이 프로그램은 유튜브 영상을 삭제하는 기능을 쓰지 않습니다**(소스 공개). 파일은 휴지통으로만 보냅니다.

**Q. 여러 명이 써도 되나요?**
네. 각자 자기 컴퓨터에서 자기 구글 계정으로 쓰기 때문에 서로 영향을 주지 않습니다.
다만 프로그램에 들어 있는 기본 열쇠는 구글의 사용자 수 한도가 있을 수 있어, 그럴 때는 내 열쇠를 만들어 쓰시면 됩니다([부록 A](docs/설정안내.md#부록-a--내-구글-열쇠를-직접-만들어-쓰기-선택)).

**Q. 인스타그램·스레드도 꼭 연결해야 하나요?**
아니요. 선택 기능입니다. 연결하지 않으면 유튜브만 올리고, 연결해도 채널마다 켜 둔 곳만 올립니다 ([5. 인스타그램 릴스·스레드에도 올리기](#5-인스타그램-릴스스레드에도-올리기-선택)).

## 문제가 생기면

위쪽 **신호등**(문제 목록)을 먼저 눌러 보세요. 오류·작업불이행·경고가 이유와 함께 나옵니다.
그래도 모르겠으면 **기록** 탭의 기록을 알려주시면 원인을 찾을 수 있습니다.

기록 파일 위치 (`기록` 폴더 안에 `서버.log` · `올리기.log` …)
- 맥 — `~/Library/Application Support/가라사대업로더/기록/`
- 윈도우 — `%APPDATA%\가라사대업로더\기록\`
