# 가라사대 업로더

**폴더에 영상을 저장하면 유튜브에 자동으로 올려줍니다.**

> ### 💬 의견을 들려주세요
> 쓰시면서 불편했던 점, 있었으면 하는 기능, 오류를 알려주시면 하나하나 읽고 반영합니다.
>
> | | |
> |---|---|
> | 🐞 **[오류가 나요](https://github.com/beautifulahin/garasadae-uploader/issues/new?template=1_bug.yml)** | 프로그램이 제대로 동작하지 않을 때 |
> | 💡 **[이런 게 있었으면](https://github.com/beautifulahin/garasadae-uploader/issues/new?template=2_idea.yml)** | 필요한 기능을 알려주세요 |
> | 📋 **[접수된 의견 보기](https://github.com/beautifulahin/garasadae-uploader/issues)** | 다른 분들이 남긴 의견과 처리 상황 |
>
> 프로그램의 **💬 의견 보내기** 탭에서 보내시면 환경 정보가 자동으로 채워집니다.

영상 만들고 나서 유튜브 열고, 업로드 누르고, 제목 넣고, 기다리는 일을 안 해도 됩니다.
바탕화면 폴더에 저장만 하면 알아서 올라갑니다.

- 맥 · 윈도우 모두 됩니다
- 설치할 것 없습니다. 받아서 실행만 하면 됩니다
- 무료입니다

---

## 1. 내려받기

**[⬇️ 여기서 받으세요](https://github.com/beautifulahin/garasadae-uploader/releases/latest)**

| 내 컴퓨터 | 받을 파일 |
|---|---|
| 윈도우 10 / 11 | `garasadae-uploader-windows.zip` |
| 맥 (Apple 칩) | `garasadae-uploader-mac-apple-silicon.zip` |
| 맥 (Intel 칩) | `garasadae-uploader-mac-intel.zip` |

> **내 맥이 어느 쪽인지 모르겠다면**
> 왼쪽 위 사과 모양 → **이 Mac에 관하여** → **칩** 항목을 보세요.
> `Apple` 로 시작하면 Apple 칩, `Intel` 이면 Intel 입니다. 요즘 맥은 대부분 Apple 칩입니다.

## 2. 실행하기

압축을 풀고 실행합니다. **처음 한 번만** 이렇게 열어야 합니다.

- **맥** — 아이콘에 **오른쪽 클릭 → 열기** → 경고창에서 다시 **열기**
- **윈도우** — 파란 경고창의 **추가 정보** → **실행**

인증 비용을 들이지 않은 개인 배포 프로그램이라 나오는 안내입니다. 다음부터는 그냥 열립니다.

## 3. 구글 계정 연결하기 (처음 한 번, 약 10분)

실행하면 브라우저에 설정 화면이 열립니다.
**시작하기** 탭을 눌러 안내대로 따라 하시면 됩니다.

> 📖 **[자세한 설정 안내서](docs/설정안내.md)** — 화면을 보면서 따라 하실 수 있게 단계별로 정리해 두었습니다.
> 막히는 곳이 있으면 안내서 맨 아래 **막혔을 때** 를 보세요.

## 4. 쓰기

바탕화면에 저절로 생긴 **업로드대기** 폴더에 영상을 저장하면 끝입니다.
프로그램 화면에 **끌어다 놓아도** 됩니다.

## 자주 묻는 것

**Q. 돈 드나요?**
전부 무료입니다. 프로그램도, 구글 설정도 요금이 나가지 않습니다.

**Q. 하루에 몇 개까지 올릴 수 있나요?**
구글이 정한 한도 때문에 **하루 6개** 입니다.
넘긴 영상은 사라지지 않고 폴더에서 기다리다가 다음 날 자동으로 올라갑니다.

**Q. 올린 영상이 바로 공개되나요?**
아니요. **비공개**로 올라갑니다. 유튜브 스튜디오에서 확인하고 직접 공개로 바꾸시면 됩니다.
설정에서 바로 공개되도록 바꿀 수도 있습니다.

**Q. 편집 프로그램에서 내보내는 중에 폴더에 들어가면요?**
저장이 완전히 끝날 때까지 기다렸다가 올립니다. 잘린 영상이 올라가지 않습니다.

**Q. 업로드 중에 인터넷이 끊기면요?**
끊긴 지점부터 이어서 올립니다. 처음부터 다시 올리지 않습니다.

**Q. 창을 닫으면 멈추나요?**
설정에서 **컴퓨터 켤 때 자동 실행** 을 켜두면 창을 닫아도, 컴퓨터를 껐다 켜도 계속 동작합니다.

**Q. 올린 뒤 원본 파일은 어떻게 되나요?**
설정에서 고를 수 있습니다 — `_완료` 폴더로 옮기기 / 휴지통 / 완전 삭제 / 그대로 두기.
어느 쪽이든 **유튜브에 실제로 올라간 것을 확인한 뒤에만** 처리합니다.

**Q. 제 구글 계정 정보가 만든 사람에게 넘어가나요?**
아닙니다. 로그인 정보는 본인 컴퓨터에만 저장됩니다.
각자 자기 구글 계정으로 직접 연결하는 방식이라 다른 사람이 볼 수 없습니다.

**Q. 유튜브 영상이 지워질 수도 있나요?**
없습니다. 이 프로그램은 구글에서 **업로드 권한만** 받고 삭제 권한은 아예 받지 않습니다.

**Q. 여러 명이 써도 되나요?**
네. 각자 자기 구글 계정으로 쓰기 때문에 인원 제한이 없고 서로 영향을 주지 않습니다.

## 의견 보내기

프로그램의 **💬 의견 보내기** 탭이 가장 편합니다. 보내면 바탕화면 `가라사대_피드백.txt` 에도 저장되고,
깃허브 작성 창이 내용이 채워진 채로 열립니다.

- 🐞 [오류 신고](https://github.com/beautifulahin/garasadae-uploader/issues/new?template=1_bug.yml)
- 💡 [기능 요청](https://github.com/beautifulahin/garasadae-uploader/issues/new?template=2_idea.yml)
- 📋 [접수된 의견 목록](https://github.com/beautifulahin/garasadae-uploader/issues)

## 문제가 생기면

프로그램 **기록** 탭에 무슨 일이 있었는지 남습니다. 그 내용을 알려주시면 원인을 찾을 수 있습니다.

기록 파일 위치
- 맥 — `~/Library/Application Support/가라사대업로더/uploader.log`
- 윈도우 — `%APPDATA%\가라사대업로더\uploader.log`
