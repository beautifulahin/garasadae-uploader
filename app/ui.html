🚀 처음 한 번만 하면 됩니다

  
유튜브에 자동으로 올리려면 구글에서 내 계정 전용 열쇠를 발급받아야 합니다. 아래 순서대로 따라오세요. 약 10분 걸립니다.

  

    
  


  

    
❓ 왜 이런 게 필요한가요?

    
구글은 프로그램이 유튜브에 영상을 올릴 때 누구의 권한으로 올리는지를 반드시 확인합니다.
    이 열쇠는 여러분 계정에서만 쓰이고, 이 프로그램을 만든 사람도 볼 수 없습니다.
    또한 하루 업로드 한도가 계정마다 따로 주어지기 때문에, 각자 발급받는 편이 훨씬 유리합니다.

  


  

    
1️⃣ 구글 클라우드에 프로젝트 만들기

    
    
      
  1. 아래 버튼으로 구글 클라우드 콘솔에 들어갑니다 (유튜브 채널이 있는 계정으로 로그인).
    2. 
      
  2. 화면 위쪽 프로젝트 선택 → 새 프로젝트 → 이름은 아무거나 (예: 내업로더) → 만들기
    3. 
    

    
  


  

    
2️⃣ 유튜브 API 켜기 가장 많이 빠뜨리는 단계

    
    
      
  1. 아래 버튼을 누르면 YouTube Data API v3 페이지가 열립니다.
    2. 
      
  2. 화면 위쪽에 방금 만든 프로젝트가 선택되어 있는지 꼭 확인하세요.
    3. 
      
  3. 파란 사용(ENABLE) 버튼을 누릅니다.
    4. 
      
  4. 버튼이 관리(MANAGE)로 바뀌면 켜진 것입니다.
    5. 
    

    
    

      ⚠️ 이 단계를 건너뛰면 영상이 하나도 올라가지 않습니다.

      로그인까지는 멀쩡히 되기 때문에 다 됐다고 착각하기 쉽습니다. 반드시 사용 버튼을 누르세요.

      누른 뒤 구글에 반영되기까지 1~2분 걸립니다. 바로 안 되면 잠시 기다렸다 다시 시도하세요.
    

  


  

    
3️⃣ 동의 화면 만들기

    
    
      
  1. 아래 버튼 → 외부 선택 → 만들기
    2. 
      
  2. 앱 이름·이메일을 채우고 계속 (개발자 연락처에도 같은 이메일)
    3. 
      
  3. 범위 단계에서 범위 추가 또는 삭제 → 검색창에 youtube.upload → 체크 → 업데이트
    4. 
      
  4. 저장하고 계속을 눌러 끝까지 진행합니다.
    5. 
    

    
    

      ⚠️ 꼭 하세요 — 게시 상태를 '프로덕션'으로 바꾸기

      동의 화면 첫 페이지에 앱 게시 버튼이 있습니다. 이걸 누르지 않고 테스트 상태로 두면
      7일마다 로그인이 풀립니다. 프로덕션으로 바꿔야 계속 자동으로 올라갑니다.
      (본인만 쓰는 앱이므로 구글 심사를 받지 않아도 동작합니다)
    

  


  

    
4️⃣ 열쇠(클라이언트 ID) 발급받기

    
    
      
  1. 아래 버튼 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID
    2. 
      
  2. 애플리케이션 유형은 반드시 데스크톱 앱을 고릅니다.
    3. 
      
  3. 만들기를 누르면 클라이언트 ID와 클라이언트 보안 비밀번호가 나옵니다. 두 개 다 복사해 두세요.
    4. 
    

    
  


  

    
5️⃣ 여기에 붙여넣고 연결하기

    
    
    
    
    
    
    

      “Google에서 확인하지 않은 앱” 경고가 떠도 정상입니다.

      본인이 직접 만든 앱이라 그렇습니다. 고급 → (앱 이름)(으)로 이동 을 눌러 계속 진행하세요.
    

  


  

    
6️⃣ 영상을 저장할 폴더 정하기

    
이 폴더에 영상을 저장하면 자동으로 업로드됩니다.
    아래 폴더가 기본으로 자동 생성되어 있으니 그대로 쓰셔도 되고, 원하는 폴더로 바꾸셔도 됩니다.

    
-

    

      
      
    

  


  

    
7️⃣ 끝났습니다

    
이제 그 폴더에 영상을 저장하기만 하면 됩니다.
    설정 탭에서 컴퓨터 켤 때 자동 실행을 켜두면 이 창을 닫아도 계속 동작합니다.

  


  

    
🚨 "액세스가 차단됨" 이 나온다면

    
구글 로그인 화면에 뜬 작은 글씨 한 줄이 원인을 알려줍니다. 해당하는 항목을 찾아보세요.


    

      
"앱이 Google 인증 절차를 완료하지 않았습니다"
또는 오류 403: access_denied

      
가장 흔한 경우입니다. 동의 화면이 아직 테스트 상태라 등록된 계정만 쓸 수 있습니다.

      동의 화면에서 앱 게시를 누르거나, 테스트 사용자에 본인 지메일을 추가하세요.
      

    


    

      
"이 앱의 요청이 잘못되었습니다"
또는 오류 400: redirect_uri_mismatch

      
클라이언트 유형이 데스크톱 앱이 아닐 때 납니다. 사용자 인증 정보에서 새로 만들 때
      애플리케이션 유형을 반드시 데스크톱 앱으로 고르세요. (웹 애플리케이션 아님)
      

    


    

      
"오류 401: invalid_client"

      
클라이언트 ID나 보안 비밀번호가 잘못 붙여넣어졌습니다. 설정 탭에서 두 값을 다시 복사해 넣어주세요.
      앞뒤 공백이 섞이지 않았는지 확인하세요.

    


    

      
"관리자가 액세스를 차단했습니다"
또는 admin_policy_enforced

      
회사·학교에서 발급한 구글 계정은 관리자가 외부 앱 접근을 막아둔 경우가 많습니다.
      개인 지메일 계정으로 다시 시도하세요.

    


    

      
"Google에서 확인하지 않은 앱"

      
이건 차단이 아니라 정상 안내입니다. 고급 → (앱 이름)(으)로 이동을 누르면 계속 진행됩니다.
      본인이 만든 앱이라 뜨는 화면입니다.

    


    

      
로그인은 됐는데 "채널을 찾을 수 없습니다"

      
그 구글 계정에 유튜브 채널이 없습니다. 유튜브에서 채널을 먼저 만든 뒤 다시 연결하세요.
