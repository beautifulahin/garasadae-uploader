📖 여러 채널 쓰는 법


    

      
①

      

        
채널마다 폴더가 하나씩 생깁니다

        
채널을 만들면 그 이름으로 폴더가 자동으로 만들어집니다.
        그 폴더에 영상을 저장하면 해당 채널로만 올라갑니다. 손댈 것이 없습니다.

        
업로드대기/
├── 모든채널/   ← 여러 채널에 같이 올릴 때
├── 채널1/     ← 넣으면 채널1 로 자동
├── 채널2/     ← 넣으면 채널2 로 자동
└── 채널3/

      

    


    

      
②

      

        
같은 영상을 여러 채널에 올리려면

        
모든채널 폴더에 몰아넣으세요. 이 폴더의 영상은 바로 올라가지 않고 기다립니다.

        첫 화면의 🌐 전체 업로드 대기 칸에서 보낼 영상과 보낼 채널을 고른 뒤
        📤 보내기를 누르면 각 채널로 들어갑니다. 영상마다 다른 채널 조합으로 보낼 수도 있습니다.

      

    


    

      
③

      

        
채널을 추가하려면 구글 설정을 한 번 더

        
채널마다 구글 클라우드 프로젝트를 따로 만들어야 하루 업로드 개수를 각각 받습니다.
        시작하기 탭의 1~4단계를 채널 수만큼 반복하시면 됩니다. 구글 계정은 하나여도 됩니다.

        

          
프로젝트 따로채널당 하루 6개 · 채널 3개면 18개

          
프로젝트 공유여러 채널이 하루 6개를 나눠 씀

        

        
가끔만 올리는 채널이라면 아래 기존 채널과 같이 쓰기로 설정을 건너뛸 수 있습니다.

      

    


    

      
④

공개 범위 · 카테고리 · 제목 앞뒤 문구 · 태그 · 설명 · 하루 한도 ·
        올린 뒤 파일 처리 · 음악 팝업 · 검토 후 업로드.
        아래 채널을 눌러 펼치면 각각 정할 수 있습니다.

        
⚠️ 같은 영상을 여러 채널에 올릴 때는 제목과 설명을 채널마다 다르게 두세요.

🚀 처음 한 번만 하면 됩니다

  
유튜브에 자동으로 올리려면 구글에서 내 계정 전용 열쇠를 발급받아야 합니다.
  채널 하나당 약 10분입니다.

  

    
  


  

    
❓ 왜 이런 게 필요한가요?

    
구글은 프로그램이 유튜브에 영상을 올릴 때 누구의 권한으로 올리는지를 반드시 확인합니다.
    이 열쇠는 여러분 계정에서만 쓰이고, 이 프로그램을 만든 사람도 볼 수 없습니다.
    또한 하루 업로드 한도가 열쇠마다 따로 주어지기 때문에, 채널마다 따로 만들면 그만큼 더 올릴 수 있습니다.

  


  

    
0️⃣ 구글 계정 2단계 인증 켜기 안 켜면 아예 못 들어갑니다

    
구글이 2026년 5월 31일부터 2단계 인증(2SV)을 켠 계정만 클라우드 콘솔을 쓸 수 있게 바꿨습니다.
    안 켜져 있으면 「Google Cloud 액세스 차단됨」 이 뜨고 아래 1️⃣ 부터 아무것도 못 합니다.

    
    
      
  1. 아래 버튼 → 2단계 인증 사용 을 켭니다.
    2. 
      
  2. 가장 쉬운 방법은 휴대전화에서 알림 받기 입니다. 내 폰에서 「예, 접니다」를 누르면 끝입니다. 문자(SMS)로 받아도 됩니다.
    3. 
      
  3. 백업 코드가 나오면 꼭 저장해 두세요. 휴대폰을 잃어버렸을 때 들어갈 유일한 길입니다.
    4. 
      
  4. 켜고 나서 몇 분 걸릴 수 있습니다. 차단 화면에서 새로고침 하세요.
    5. 
    

    
    

      이미 켜져 있다면 그냥 넘어가세요. 새로고침해도 계속 차단되면 구글에서 로그아웃했다가 다시 로그인하면 풀립니다.
    

  


  

    
1️⃣ 구글 클라우드에 프로젝트 만들기

    
    
      
  1. 아래 버튼으로 구글 클라우드 콘솔에 들어갑니다 (그 채널을 가진 계정으로 로그인).
    2. 
      
  2. 화면 위쪽 프로젝트 선택 → 새 프로젝트 → 이름은 아무거나 → 만들기
    3. 
      
  3. 만든 뒤 위쪽에 그 프로젝트가 선택되어 있는지 꼭 확인하세요.
    4. 
    

    
    

      ⚠️ 「무료로 시작하기」는 누르지 마세요

      검색해서 cloud.google.com 으로 들어가면 무료로 시작하기 버튼밖에 안 보이는데,
      그것은 신용카드를 등록하는 무료 체험 가입입니다. 우리와는 상관없습니다.
      위 버튼을 쓰시면 바로 프로젝트 만드는 화면으로 갑니다 — 카드 등록도 결제도 필요 없습니다.

      콘솔에 처음 들어가면 국가 선택과 약관 동의가 한 번 나올 수 있습니다. 그것은 결제와 무관하니 넘어가시면 됩니다.
    

  


  

    
2️⃣ 유튜브 API 켜기 가장 많이 빠뜨리는 단계

    
    
      
  1. 아래 버튼을 누르면 YouTube Data API v3 페이지가 열립니다.
    2. 
      
  2. 위쪽에 방금 만든 프로젝트가 선택되어 있는지 확인하세요.
    3. 
      
  3. 파란 사용(ENABLE) 버튼을 누릅니다.
    4. 
      
  4. 버튼이 관리(MANAGE)로 바뀌면 켜진 것입니다.
    5. 
    

    
    

      ⚠️ 이 단계를 건너뛰면 영상이 하나도 올라가지 않습니다.

      로그인까지는 멀쩡히 되기 때문에 다 됐다고 착각하기 쉽습니다. 반드시 사용 버튼을 누르세요.

      누른 뒤 반영되기까지 1~2분 걸립니다.
    

  


  

    
3️⃣ 인증 플랫폼 만들고 게시하기

    
구글이 이 화면을 「Google 인증 플랫폼」으로 새로 바꿨습니다. 예전 「OAuth 동의 화면」과 같은 것인데,
    왼쪽에 브랜딩 · 대상 · 클라이언트 · 데이터 액세스 로 갈라져 있습니다.

    
    
      
  1. 아래 버튼으로 들어가 시작하기 를 누릅니다. (이미 만드셨으면 이 버튼이 안 보입니다 — 그냥 다음으로)
    2. 
      
  2. 앱 정보 — 앱 이름은 아무거나, 사용자 지원 이메일은 본인 지메일
    3. 
      
  3. 대상 — 외부 를 고릅니다
    4. 
      
  4. 연락처 정보 — 본인 지메일을 채웁니다
    5. 
      
  5. 정책 동의에 체크하고 만들기
    6. 
    

    
그 다음 — 왼쪽 메뉴에서 두 가지를 더 합니다. 순서가 중요합니다.

    
    
      
  1. 데이터 액세스 → 범위 추가 또는 삭제 → 필터에 youtube.upload → 체크 →
      업데이트 → 저장
    
      필터에 쳐도 안 나오면 같은 패널의 범위를 수동으로 추가 칸에
      https://www.googleapis.com/auth/youtube.upload 를 붙여넣고 테이블에 추가
    2. 
      
  2. 대상 → 앱 게시 를 눌러 프로덕션으로 바꿉니다
    3. 
    

    
    

      ⚠️ 범위가 먼저, 앱 게시가 나중입니다.

      범위는 동의 화면 만들기 안에 없습니다. 왼쪽 데이터 액세스 메뉴에 따로 있습니다. 저장까지 꼭 누르세요.

      앱 게시를 안 하고 테스트 상태로 두면 7일마다 로그인이 풀립니다.
    

  


  

    
4️⃣ 열쇠(클라이언트 ID) 발급받기

    
    
      
  1. 아래 버튼 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID
    2. 
      
  2. 애플리케이션 유형은 반드시 데스크톱 앱
    3. 
      
  3. 만들면 클라이언트 ID와 보안 비밀번호가 나옵니다. 둘 다 복사해 두세요.
    4. 
    

    
    
새 화면(인증 플랫폼)에서는 왼쪽
    클라이언트 → 클라이언트 만들기 로도 똑같이 만들 수 있습니다. 이름만 다르고 같은 것입니다.

    

      ⚠️ 「웹 애플리케이션」을 고르면 로그인할 때 「액세스가 차단됨」 오류가 납니다. 꼭 데스크톱 앱입니다.
    

  


  

    
5️⃣ 채널 등록하고 연결하기

    
채널 탭으로 가서 ➕ 채널 추가 에 이름과 방금 복사한 두 값을 넣고 만드세요.
    만들면 그 채널의 🔑 구글 계정 연결 버튼이 생깁니다.

    
    

      “Google에서 확인하지 않은 앱” 경고가 떠도 정상입니다.

      본인이 직접 만든 앱이라 그렇습니다. 고급 → (앱 이름)(으)로 이동 을 눌러 계속 진행하세요.
    

  


  

    
6️⃣ 채널을 더 늘리려면

    
채널마다 1️⃣~5️⃣ 를 다시 하시면 됩니다. 구글 계정은 하나여도 됩니다 —
    한 계정 안에서 프로젝트를 여러 개 만들 수 있고, 로그인할 때 어느 채널에 연결할지 고르게 됩니다.

    가끔만 올리는 채널이라면 채널 추가에서 기존 채널과 같이 쓰기 를 골라 설정을 건너뛸 수 있습니다.
    다만 그 경우 하루 6개를 두 채널이 나눠 씁니다.

      여러 채널에 같이 올릴 영상 — 모든채널 폴더에 넣고, 첫 화면
      🌐 전체 업로드 대기 에서 영상과 채널을 골라 보내기를 누르세요.

🚨 "액세스가 차단됨" 이 나온다면

    
구글 로그인 화면에 뜬 작은 글씨 한 줄이 원인을 알려줍니다.

    

      
"앱이 Google 인증 절차를 완료하지 않았습니다"
오류 403: access_denied

      
가장 흔합니다. 동의 화면이 테스트 상태입니다.
      앱 게시를 누르거나 테스트 사용자에 본인 지메일을 추가하세요.
      

    

    

      
"이 앱의 요청이 잘못되었습니다"
오류 400: redirect_uri_mismatch

      
클라이언트 유형이 데스크톱 앱이 아닙니다. 4️⃣ 를 다시 하세요.

    

    

      
"오류 401: invalid_client"

      
클라이언트 ID나 보안 비밀번호가 잘못 붙여넣어졌습니다. 앞뒤 공백을 확인하세요.

    

    

      
"관리자가 액세스를 차단했습니다"

      
회사·학교 계정입니다. 개인 지메일 계정으로 하세요.
