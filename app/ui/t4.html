⚙️ 설정
모든 채널에 공통으로 적용되는 설정입니다. 채널별 설정은 채널 탭에 있습니다.

🤖 AI 열쇠를 넣으면 제목·설명·해시태그를 자동으로 지어 줍니다

지금은 열쇠가 없어서 문안이 없는 영상은 파일 이름이 제목으로 올라갑니다. 이 컴퓨터에 이미 있는 열쇠를 찾아 드리고, 없으면 구글 AI 스튜디오에서 무료 열쇠를 받아 넣으면 됩니다.

📂 새 채널의 영상 폴더가 들어갈 상위 폴더

바탕화면을 지켜보는 폴더가 아닙니다. 새 채널을 만들면 그 채널의 영상 폴더가 이 안에 채널 이름으로 생깁니다. 이미 만든 채널의 폴더는 바뀌지 않습니다.

🔧 동작

구글 로그인 창 같은 것을 띄울 브라우저입니다. 기본값으로 두면 이 컴퓨터의 기본 브라우저로 열립니다. 편집기 같은 프로그램이 기본으로 잡혀 있어 창이 이상하게 열린다면 여기서 브라우저를 골라 주세요.
업로드 완료·오류 시 컴퓨터 알림 표시
컴퓨터 켤 때 자동 실행 — 켜면 10분마다 올릴 시각과 심사 결과를 확인하는 작업도 함께 켭니다
두 가지가 함께 켜집니다 — ① 컴퓨터를 켤 때 이 프로그램을 실행 ② 10분마다 올릴 시각·심사 결과를 확인하는 작업. 맥에서는 로그인 항목 두 개로, 윈도우에서는 시작 프로그램과 예약 작업으로 등록됩니다. 끄면 둘 다 지웁니다.
🔔 텔레그램 알림 선택
막힌 소식(로그인이 풀림·올리기 실패 같은 것)을 폰으로 받고 싶을 때만 쓰세요. 잘 올라간 소식은 보내지 않습니다. 봇 토큰은 이 컴퓨터에만 저장되고, 저장한 뒤에는 화면에 다시 보이지 않습니다.
봇 토큰은 텔레그램에서 @BotFather 로 봇을 만들면 받습니다. 받는 사람 번호는 숫자(채팅 번호)입니다. 받는 사람만 바꿀 때도 토큰을 다시 넣어 주세요.
막힌 소식을 텔레그램으로도 보내기 — 아래 「설정 저장」을 눌러야 적용됩니다

🛡 운영 원칙

영상마다 정하는 값이 아니라 채널 운영 방침입니다. 올리는 모든 영상에 똑같이 적용됩니다.
아동용 콘텐츠로 표시 — 법적으로 신고해야 하는 항목입니다. 보통은 꺼 둡니다(아동용 콘텐츠 아님). 채널 하나만 다르게 하려면 채널 탭에서 정하세요.
AI 로 만든(합성) 영상으로 표시 — 영상이 AI 합성물이면 켜세요. 유튜브가 요구하는 공개 항목입니다.

🗂 경로 선택

비워 두면 알아서 정합니다. 꼭 필요할 때만 바꾸세요.
ffprobe 가 없어도 괜찮습니다 — 영상의 길이와 화면 비율은 파일에서 직접 읽습니다.
위 카드(폴더·동작·운영 원칙·경로)를 저장합니다. 아래 AI·쿠팡 카드는 카드마다 따로 저장합니다.

🤖 제목·설명 자동으로 짓기 -

쪽지·직접 쓴 문안이 없는 영상은 올리기 직전에 영상 내용과 이 채널의 말투를 보고 제목·설명·해시태그를 지어 넣습니다. 파일 이름 그대로 올라가지 않습니다. 영상 하나에 20~30초쯤 더 걸립니다. 쇼츠는 짧게, 롱폼은 길게 형식이 다르게 지어집니다.
열쇠는 본인 것(구글 AI 스튜디오, 무료)을 씁니다. 열쇠 값은 화면에 보이지 않습니다(저장됨 여부만 표시).
영상 보고 제목·설명 짓기 — 기본 켜짐 · 바로 적용됩니다
우선순위: 사람이 화면에서 고친 것 > 쪽지 > 자동 생성 > 파일 이름. 제목·설명·태그 칸마다 따로 정해집니다.
켜면 올리기 직전에 영상이 구글로 한 번 올라갔다가 곧바로 지워집니다 — 제목을 지으려면 구글이 영상을 봐야 하기 때문입니다.
끄면 아무것도 올라가지 않습니다. 직접 쓴 문안·쪽지가 늘 먼저입니다.

🛒 쿠팡 파트너스 -

영상마다 소재에 맞는 상품 링크를 설명 끝에 자동으로 붙입니다. 내 파트너스 열쇠를 넣으면 수수료가 내 계정으로 들어갑니다. 관련 상품이 없으면(정치·뉴스 등) 억지로 붙이지 않고, 링크를 못 붙여도 업로드는 그대로 진행됩니다.
열쇠 값은 화면에 보이지 않습니다(저장됨 여부만 표시).
쿠팡 자동 링크 켜기 — 바로 적용됩니다 · 채널마다 따로 끄려면 채널 탭에서
쿠팡 파트너스 검색 API 는 시간당 호출 횟수가 제한되어 있어(기본 10회), 이 한도를 넘기면 그 시간에는 링크를 붙이지 않고 업로드만 진행합니다.
수수료 집계에서 채널을 구분하는 코드입니다. 채널마다 다르게 하려면 채널 탭에서 따로 정하세요.
⚠️ 고지문은 바꾸지 마세요. 쿠팡 파트너스 활동 고지문입니다. 바꾸거나 지우면 정책 위반이 될 수 있으니 그대로 두세요.

📷 인스타그램·스레드 -

유튜브에 올린 쇼츠가 공개되는 때에 맞춰 인스타그램 릴스와 스레드에도 같은 영상을 자동으로 올립니다. 롱폼·가로 영상은 올리지 않고, 올리다 실패해도 유튜브 쪽에는 아무 영향이 없습니다. 인스타그램은 비즈니스 또는 크리에이터 계정이어야 하고, 메타 앱 심사가 끝나기 전에는 앱에 초대된 테스터 계정만 올릴 수 있습니다.
로그인만 하면 됩니다. 열쇠나 비밀번호를 이 앱에 입력하지 않습니다.
채널마다 올릴 계정 (기본은 끔)
영상 하나만 켜거나 끄려면 영상 옆 쪽지(json)에 "instagram": true · "threads": false 처럼 적으세요. 쪽지가 채널 설정보다 먼저입니다.
최근 결과
아직 없습니다.
올리는 중에 연결이 끊겨 올라갔는지 알 수 없는 영상은 같은 영상이 두 번 올라가지 않도록 다시 보내지 않습니다. 계정의 최근 게시물에서 찾아 보거나, 직접 확인하고 「올라갔음 / 안 올라갔음」을 눌러 주세요.

🧰 점검·보관

환경 점검은 이 컴퓨터의 환경(ffmpeg·필요한 파일 등)을 읽기만 합니다. 점검은 사람이 시키지 않았는데 유튜브를 부르는 일이 없는지 확인합니다. 오늘치 보관은 놓치면 되살릴 수 없는 기록(조회수·구독자 기록 등)을 날짜별로 따로 남겨 둡니다. 외장 백업은 이 컴퓨터를 원본으로 외장하드에 사본을 만듭니다(외장하드가 없으면 건너뜁니다).
