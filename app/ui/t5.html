🚀 처음 한 번만 하면 됩니다
유튜브에 올리려면 구글 계정으로 로그인해서 채널을 연결하면 됩니다. 구글 클라우드에서 열쇠를 만들 필요가 없습니다 — 필요한 열쇠는 이 프로그램에 이미 들어 있습니다.
① 채널 이름 만들기 ② 구글 계정 연결 ③ 영상 넣기 ④ AI 열쇠 넣기 (선택) ⑤ 쿠팡 파트너스 연결 (선택) ⑥ 올리기

🤖 AI 열쇠를 넣으면 제목·설명·해시태그를 자동으로 지어 줍니다

지금은 열쇠가 없어서 문안이 없는 영상은 파일 이름이 제목으로 올라갑니다. 아래 4️⃣ 를 따라 열쇠를 넣어 주세요.

❓ 왜 구글 로그인이 필요한가요?

구글은 프로그램이 유튜브에 영상을 올릴 때 누구의 권한으로 올리는지를 반드시 확인합니다. 로그인 창에서 허용하면 이 컴퓨터에만 연결 정보가 저장되고, 이 프로그램을 만든 사람도 볼 수 없습니다. 요청하는 권한은 세 가지뿐입니다.
⬆️ 업로드영상을 올립니다
👁 읽기채널 정보와 조회수를 읽습니다
🌐 공개 전환비공개로 올린 영상을 심사 뒤 공개로 바꿉니다
로그인 창에는 이 세 가지가 칸으로 나뉘어 보입니다(공개 전환은 구글이 「YouTube 계정 관리」 같은 이름으로 보여 줍니다). 세 칸 모두 체크해 주세요. 하나라도 빼면 그 일을 못 합니다(공개 전환 칸을 빼면 채널 카드에 「공개 권한 없음」이라고 뜹니다) — 그때는 다시 연결하면 됩니다.

1️⃣ 채널 이름 만들기

  1. 📺 채널 탭 아래쪽 ➕ 채널 추가 에 이름을 적습니다. (예: 채널1)
  2. 이름으로 영상 폴더가 하나 생깁니다. 이 채널에 올릴 영상은 그 폴더에 넣습니다.
이름을 안 정하고 바로 2️⃣ 로 가도 됩니다 — 로그인 창에서 고른 유튜브 채널 이름으로 자동 등록됩니다.

2️⃣ 구글 계정 연결 채널마다 한 번

  1. 채널 카드(또는 채널 탭 맨 위)의 🔑 구글 계정 연결 을 누르면, 이 컴퓨터의 브라우저에 구글 로그인 창이 열립니다.
  2. 그 채널을 가진 구글 계정으로 로그인하세요. 계정이 하나여도 됩니다.
  3. 이번에 등록할 채널을 고르는 화면이 나오면 그 채널을 고릅니다. (채널이 여럿이면 매번 이 화면이 나옵니다)
  4. 권한 세 칸을 모두 체크하고 허용을 누르면 끝입니다. 채널 이름·배너·프로필 사진은 알아서 받아 둡니다.
  5. 채널이 더 있으면 다음 채널 이어서 연결 을 눌러 같은 방법을 반복하세요. 계정을 바꿔 고르는 화면이 매번 뜹니다.
📟 이 컴퓨터 앞에 채널 주인이 없다면 — 코드 인증
채널 카드의 📟 코드 인증 을 누르면 화면에 주소와 8자리 코드가 뜹니다. 채널 주인에게 알려 주세요. 주인이 자기 폰이나 컴퓨터에서 그 주소를 열고 코드를 넣어 승인하면 연결됩니다. 비밀번호가 오가지 않습니다.
같은 채널을 다시 연결하면 그 자리를 갱신합니다(중복으로 늘어나지 않습니다). 로그인 중에 「Google에서 확인하지 않은 앱」 경고가 뜨면 고급 → (앱 이름)(으)로 이동 을 눌러 계속 진행하세요.

3️⃣ 영상 넣기

  • 끌어다 놓기 — 영상 파일을 👀 감시 중 탭의 놓는 칸에 끌어다 놓습니다.
  • 영상 넘기기 — 다른 프로그램이나 사람이 승인한 영상을 채널 폴더로 복사해 담습니다.
  • 폴더에 직접 넣기 — 채널 카드의 📂 폴더 열기 로 그 채널 폴더를 열어 영상을 넣습니다.
제목·설명·태그는 영상 옆에 같은 이름의 문안 파일(.txt)을 두면 그대로 쓰입니다. 없으면 파일 이름이 제목이 됩니다.

4️⃣ AI 열쇠 넣기 선택

문안(제목·설명·태그)을 따로 안 써 둔 영상은 올리기 직전에 AI 가 영상 내용과 이 채널의 말투를 보고 제목·설명·해시태그를 지어 넣습니다. 기본으로 켜져 있고, 열쇠만 있으면 됩니다. 열쇠가 없으면 파일 이름이 제목이 됩니다.
  1. 아래 ✨ AI 연결 을 누르면 이 컴퓨터에 이미 있는 열쇠를 찾아 목록으로 보여 줍니다. 쓸 열쇠를 골라 이걸로 쓰기를 누르세요.
  2. 찾은 열쇠가 없으면 구글 AI 스튜디오에서 무료 열쇠를 만들어(본인 구글 계정으로) 창의 칸에 붙여넣고 연결 시험 후 저장을 누르세요.
쪽지나 직접 쓴 문안이 늘 먼저입니다 (사람이 화면에서 고친 것 > 쪽지 > 자동 생성 > 파일 이름). 자동으로 지으려면 영상이 구글로 한 번 올라갔다가 곧바로 지워집니다 — 제목을 지으려면 구글이 영상을 봐야 하기 때문입니다.

5️⃣ 쿠팡 파트너스 연결 선택

쿠팡 파트너스(partners.coupang.com)에 가입해 승인을 받은 뒤 받는 열쇠(Access Key·Secret Key)를 넣으면, 올리는 영상마다 소재에 맞는 상품 링크가 설명 끝에 자동으로 붙고 수수료가 내 계정으로 들어갑니다. 관련 상품이 없으면(정치·뉴스 등) 억지로 붙이지 않습니다. AI 연결과 같은 창에서 하며, 이 컴퓨터에 이미 있는 열쇠도 찾아 줍니다.
열쇠는 이 컴퓨터에만 저장됩니다. 채널마다 켜고 끄거나 sub ID 를 다르게 두려면 📺 채널 탭의 채널 카드에서 정하세요.

6️⃣ 올리기

  1. 👀 감시 중 탭에서 올릴 영상을 고르고 올리기 를 누릅니다.
  2. 올릴 영상 표(채널·제목·종류·올리기 시각·공개 시각)가 나옵니다. 확인하고 올리기 를 한 번 더 누르세요. 사람이 누른 것만 올라갑니다.
  3. 영상은 먼저 비공개로 올라가고, 30분쯤 뒤 자동으로 검토해서 통과하면 공개로 바뀝니다.

📏 쇼츠와 롱폼은 이렇게 갈립니다

  • 쇼츠 — 길이가 3분(180초) 이하이고 화면이 세로 또는 정사각형인 영상.
  • 롱폼 — 그 밖의 영상(3분이 넘거나 가로 화면). 올린 뒤에는 바꿀 수 없으니 올리기 전에 종류를 꼭 확인하세요.
  • 롱폼은 맞춤 썸네일이 클릭률을 좌우합니다. 영상과 같은 이름의 그림 파일(.jpg·.png, 2MB 이하)을 영상 옆에 두면 함께 올라갑니다.
채널마다 하루 몇 편까지 올릴지 정할 때도 쇼츠와 롱폼을 나눠 셀 수 있습니다 — 📺 채널 탭의 채널 카드 → 일 한도.

📊 하루에 몇 개까지 올릴 수 있나요?

  • 내가 정하는 한도 — 채널 카드의 일 한도 에서 채널마다 「하루 N편」을 정합니다. 넘치는 영상은 사라지지 않고 다음 날로 N편씩 밀려 예약됩니다.
  • 구글이 정한 하루 한도 — 구글은 하루에 쓸 수 있는 호출량을 제한하고, 영상 하나를 올리는 데 꽤 많이 듭니다. 오늘 얼마나 썼는지는 👀 감시 중 탭 오른쪽 할당량 상자에서 볼 수 있습니다.
  • 한도에 닿으면(오류 429) 남은 영상은 그대로 두었다가 구글 한도가 초기화된 뒤(한국 시각 오후 4시 10분쯤) 다음 날로 자동으로 미룹니다. 다시 올릴 필요가 없습니다.

🚨 자주 나오는 문제

구글 로그인이 7일마다 풀려요
채널 탭에서 🔑 구글 계정 연결 을 다시 누르면 됩니다. 기다리던 영상은 사라지지 않고 그대로 올라갑니다.
내 구글 열쇠(내 프로젝트)를 쓰는데 동의 화면이 「테스트」 상태이면 7일마다 풀립니다 — 아래 「내 구글 열쇠를 쓰고 싶다면」의 「라」 단계에서 앱 게시를 하면 막을 수 있습니다.
채널 카드에 「공개 권한 없음」이 떠요
로그인 창에서 권한 세 칸 중 하나를 빼고 허용했을 때 생깁니다. 그 채널을 다시 연결하면서 세 칸 모두 체크하세요.
「이 인증에 연결된 채널이 없습니다」
로그인은 됐지만 채널을 고르는 화면에서 채널을 고르지 않았거나, 그 계정에 채널이 없는 경우입니다. 다시 연결하면서 올릴 채널을 골라 주세요.
「리프레시 토큰을 못 받았습니다」
구글 계정 → 보안 → 서드파티 앱 및 서비스에서 이 앱의 기존 권한을 삭제한 뒤 다시 연결하세요.
로그인 창이 안 열리거나 엉뚱한 프로그램으로 열려요
⚙️ 설정 탭의 「화면을 띄울 브라우저」에서 브라우저를 고르세요. 그래도 안 열리면 연결 대기 화면에 나온 주소를 복사해 직접 열거나, 📟 코드 인증을 쓰세요.
「관리자가 액세스를 차단했습니다」
회사·학교 계정입니다. 개인 구글 계정으로 하거나, 조직 관리자에게 허용을 요청하세요.
로그인은 됐는데 영상이 안 올라감
채널 카드의 🔍 연결 점검 으로 연결 상태를 확인하세요. 하루 한도(오류 429)에 닿았다면 위 「하루에 몇 개까지」를 보세요.

🩺 그 밖의 오류는 오류 사전에서

지금까지 나온 오류를 종류별로 모아 두었습니다. 화면에 뜬 문구를 그대로 찾으시면 됩니다.
🔑 내 구글 열쇠를 쓰고 싶다면 (고급)
기본으로는 이 프로그램에 들어 있는 열쇠로 연결되므로 이 구역은 건너뛰셔도 됩니다. 내 구글 클라우드 프로젝트의 열쇠를 쓰고 싶을 때만 아래를 따라 하세요. 만든 열쇠 파일은 📺 채널 탭의 「🔑 내 구글 열쇠 쓰기」에서 넣습니다. 열쇠는 두 벌(구글 로그인용 데스크톱 앱 · 코드 인증용 TV 및 입력 제한 기기)이고, 허락 범위는 위에서 본 세 가지입니다.

가. 구글 계정 2단계 인증 켜기 안 켜면 아예 못 들어갑니다

구글이 2026년 5월 31일부터 2단계 인증(2SV)을 켠 계정만 클라우드 콘솔을 쓸 수 있게 바꿨습니다. 안 켜져 있으면 「Google Cloud 액세스 차단됨」 이 뜨고 아래 「나」 단계부터 아무것도 못 합니다.
  1. 아래 버튼 → 2단계 인증 사용 을 켭니다.
  2. 가장 쉬운 방법은 휴대전화에서 알림 받기 입니다. 내 폰에서 「예, 접니다」를 누르면 끝입니다. 문자(SMS)로 받아도 됩니다.
  3. 백업 코드가 나오면 꼭 저장해 두세요. 휴대폰을 잃어버렸을 때 들어갈 유일한 길입니다.
  4. 켜고 나서 몇 분 걸릴 수 있습니다. 차단 화면에서 새로고침 하세요.
이미 켜져 있다면 그냥 넘어가세요. 새로고침해도 계속 차단되면 구글에서 로그아웃했다가 다시 로그인하면 풀립니다.

나. 구글 클라우드에 프로젝트 만들기

  1. 아래 버튼으로 구글 클라우드 콘솔에 들어갑니다 (그 채널을 가진 계정으로 로그인).
  2. 화면 위쪽 프로젝트 선택 → 새 프로젝트 → 이름은 아무거나 → 만들기
  3. 만든 뒤 위쪽에 그 프로젝트가 선택되어 있는지 꼭 확인하세요.
⚠️ 「무료로 시작하기」는 누르지 마세요
검색해서 cloud.google.com 으로 들어가면 무료로 시작하기 버튼밖에 안 보이는데, 그것은 신용카드를 등록하는 무료 체험 가입입니다. 우리와는 상관없습니다. 위 버튼을 쓰시면 바로 프로젝트 만드는 화면으로 갑니다 — 카드 등록도 결제도 필요 없습니다.
콘솔에 처음 들어가면 국가 선택과 약관 동의가 한 번 나올 수 있습니다. 그것은 결제와 무관하니 넘어가시면 됩니다.

다. 유튜브 API 켜기 가장 많이 빠뜨리는 단계

  1. 아래 첫 번째 버튼을 누르면 YouTube Data API v3 페이지가 열립니다. 영상 올리기·공개 전환·조회에 꼭 필요합니다.
  2. 위쪽에 방금 만든 프로젝트가 선택되어 있는지 확인하고, 파란 사용(ENABLE) 버튼을 누릅니다. 관리(MANAGE)로 바뀌면 켜진 것입니다.
  3. 같은 방법으로 YouTube Analytics API 도 켭니다. 📊 성적 탭의 조회수·시청 시간에 쓰입니다.
⚠️ Data API 를 건너뛰면 영상이 하나도 올라가지 않습니다.
로그인까지는 멀쩡히 되기 때문에 다 됐다고 착각하기 쉽습니다. 반드시 사용 버튼을 누르세요. 누른 뒤 반영되기까지 1~2분 걸립니다.

라. 인증 플랫폼 만들고 게시하기

구글이 이 화면을 「Google 인증 플랫폼」으로 새로 바꿨습니다. 예전 「OAuth 동의 화면」과 같은 것인데, 왼쪽에 브랜딩 · 대상 · 클라이언트 · 데이터 액세스 로 갈라져 있습니다.
  1. 아래 버튼으로 들어가 시작하기 를 누릅니다. (이미 만드셨으면 이 버튼이 안 보입니다 — 그냥 다음으로)
  2. 앱 정보 — 앱 이름은 아무거나, 사용자 지원 이메일은 본인 지메일
  3. 대상 — 외부 를 고릅니다
