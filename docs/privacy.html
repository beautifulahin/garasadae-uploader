📺가라사대 업로더

개인정보처리방침

시행일 2026년 8월 28일

요약 — 가라사대 업로더는 사용자 본인의 컴퓨터에서만 동작하는 데스크톱 프로그램입니다. 개발자 서버가 없고, 사용자의 어떤 정보도 개발자에게 전송·수집·저장되지 않습니다. 프로그램이 다루는 정보는 전부 사용자의 컴퓨터와 사용자 본인의 구글(유튜브) 계정 사이에서만 오갑니다.

1. 다루는 정보

  • 구글 계정 인증 토큰 — 사용자가 「구글 계정 연결」로 직접 허용한 OAuth 토큰. 사용자 컴퓨터의 프로그램 설정 폴더에만 저장됩니다.
  • 업로드할 영상 파일과 제목·설명·태그 — 사용자가 지정한 폴더에 넣은 파일. 사용자의 유튜브 채널로만 전송됩니다.
  • 업로드 기록·조회수 등 성적 — 사용자 채널의 공개 통계. 화면 표시용으로 사용자 컴퓨터에만 저장됩니다.

2. 구글 사용자 데이터의 이용

이 프로그램은 Google API(YouTube Data API)를 통해 다음 목적에만 구글 사용자 데이터를 사용합니다.

  • 사용자가 지정한 영상을 사용자 본인의 유튜브 채널에 업로드하고, 썸네일·설명·공개 설정을 지정합니다.
  • 업로드한 영상의 조회수·좋아요·댓글 수를 사용자 화면에 보여 주기 위해 읽습니다.
  • 사용자가 켠 경우에 한해, 업로드 직후 첫 댓글을 달거나 제목을 바꿉니다.

구글 사용자 데이터를 광고·판매·프로파일링·AI 모델 학습 등 다른 목적으로 사용하지 않으며, 제3자에게 제공하지 않습니다. 이 프로그램의 Google API 로부터 받은 정보의 사용과 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요건을 포함하여 그 정책을 준수합니다.

3. 저장 위치와 보관 기간

  • 모든 정보는 사용자 컴퓨터의 프로그램 설정 폴더(맥: ~/Library/Application Support/가라사대업로더, 윈도우: %APPDATA%\가라사대업로더)에만 저장됩니다.
  • 사용자가 프로그램을 지우거나 설정 폴더를 삭제하면 모든 정보가 함께 삭제됩니다.

4. 제3자 제공·외부 전송

  • 정보가 전송되는 곳은 구글(YouTube API) 뿐이며, 이는 사용자가 요청한 업로드·조회를 수행하기 위한 것입니다.
  • 사용자가 스스로 텔레그램 알림을 설정한 경우, 사용자 본인의 텔레그램 봇으로 업로드 결과 알림이 갑니다. 기본값은 꺼짐이며 개발자와 무관합니다.
  • 「제목·설명 자동으로 짓기」를 켠 경우에만, 올리려는 영상 파일이 사용자 본인의 구글 AI 스튜디오(Gemini API) 계정으로 전송되어 제목·설명·태그를 생성하는 데 쓰이고, 생성이 끝나는 즉시 프로그램이 그 파일을 삭제합니다. 사용하는 API 열쇠는 사용자가 직접 발급해 직접 입력한 본인의 열쇠이며 이 컴퓨터에만 저장됩니다. 이 기능은 기본값이 꺼짐이고, 끄면 영상은 어디로도 전송되지 않습니다. 개발자는 이 과정에 관여하지 않고 아무것도 받지 않습니다.
  • 개발자는 어떤 사용자 정보도 받지 않습니다.

5. 사용자의 권리 · 연결 해제

  • 프로그램의 「채널」 탭에서 연결 해제를 누르면 저장된 토큰이 삭제됩니다.
  • 구글 계정의 타사 앱 액세스 관리에서 언제든 이 프로그램의 권한을 철회할 수 있습니다.
  • 설정 폴더를 지우면 프로그램이 보관한 모든 정보가 삭제됩니다.

6. 아동의 개인정보

이 프로그램은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 정보를 의도적으로 수집하지 않습니다.
