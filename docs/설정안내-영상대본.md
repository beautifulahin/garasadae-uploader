# 가라사대 업로더 · 설정 안내 영상 대본

> **목적** — 처음 받은 사람이 이 영상만 보고 혼자 설정을 끝낼 수 있게 한다.
> **길이** — 10분 내외 · **녹화** — 화면 녹화 + 음성
> **가장 중요한 것** — 아래 ★ 표시 3곳. 문의의 대부분이 여기서 나온다.

---

## 녹화 전 준비

- 구글 클라우드 콘솔에서 **아직 아무것도 만들지 않은 계정**으로 녹화한다. (이미 만들어둔 화면으로 찍으면 시청자 화면과 달라져 헷갈린다)
- 브라우저 확대를 **125~150%** 로 올린다. 콘솔 글씨가 작아 모바일에서 안 보인다.
- 개인정보가 나오는 구간은 미리 정해둔다 — **클라이언트 ID·보안 비밀번호·이메일 주소**. 편집에서 흐리게 처리한다.
- 녹화용 영상 파일 하나를 미리 준비한다. (마지막 시연용, 1분 이하 짧은 것)

## 1. 프로그램 받아서 실행하기 · 1분

**화면** — 깃허브 릴리스 페이지

> 먼저 프로그램을 받겠습니다. 설명란에 있는 주소로 들어가시면 이런 화면이 나옵니다.
> 여기서 본인 컴퓨터에 맞는 걸 받으시면 되는데요.

**화면** — 파일 목록 세 개를 순서대로 가리킴

> 윈도우를 쓰시면 맨 아래 windows 라고 적힌 파일,
> 맥을 쓰시면 두 가지 중에 골라야 합니다.
>
> 내 맥이 어느 쪽인지 모르시겠으면, 화면 왼쪽 위 사과 모양을 누르시고
> '이 Mac에 관하여' 를 눌러보세요.

**화면** — 사과 메뉴 → 이 Mac에 관하여 → 칩 항목 확대

> 요즘 나온 맥은 대부분 Apple 입니다.

**화면** — 다운로드 → 압축 풀기 → 실행 시도 → 보안 경고 창

> 받으신 다음 압축을 풀고 실행하면, 이런 경고창이 뜹니다. 놀라지 않으셔도 됩니다.

**★ 함정 1 — 보안 경고**

**화면** — 맥: 우클릭 → 열기 / 윈도우: 추가 정보 → 실행

> 맥에서는 그냥 더블클릭하면 안 열립니다.
> **마우스 오른쪽 버튼을 누르고 '열기'** 를 선택하세요. 그리고 한 번 더 '열기' 를 누르시면 됩니다.
>
> 윈도우에서는 파란 화면이 뜨는데 **'추가 정보'** 를 누르시고 **'실행'** 을 누르시면 됩니다.
>
> 이건 제가 애플이나 마이크로소프트에 인증 비용을 내지 않아서 나오는 안내입니다.
> 처음 한 번만 이렇게 하시면 다음부터는 그냥 열립니다.

**자막** — `맥: 우클릭 → 열기 · 윈도우: 추가 정보 → 실행`

**화면** — 브라우저에 앱 화면이 뜨고, 바탕화면에 '업로드대기' 폴더가 생기는 장면

> 실행하면 이렇게 브라우저에 설정 화면이 열립니다.
> 그리고 바탕화면을 보시면 **업로드대기** 라는 폴더가 저절로 만들어져 있습니다.
> 나중에 여기에 영상을 넣으시면 됩니다. 폴더는 직접 만드실 필요 없습니다.

## 2. 왜 구글 설정이 필요한지 · 30초

**화면** — 앱의 '시작하기' 탭

> 이 열쇠는 여러분 컴퓨터에만 저장되고, 저를 포함해 아무도 볼 수 없습니다.
> 그리고 이렇게 각자 만들어야 하루 업로드 개수도 각자 따로 받습니다.

## 3. 구글 클라우드 프로젝트 만들기 · 1분 30초

**화면** — 앱의 1단계 카드 → 버튼 클릭 → 구글 클라우드 콘솔

> 화면에 있는 **프로젝트 만들기 열기** 버튼을 눌러주세요. 브라우저에 새 창이 열립니다.
>
> 여기서 중요한 게 하나 있습니다.
> **유튜브 채널이 있는 구글 계정으로 로그인**되어 있는지 꼭 확인하세요.
> 계정이 여러 개 있으시면 오른쪽 위에서 확인하실 수 있습니다.

**화면** — 프로젝트 이름 입력

> 프로젝트 이름은 아무거나 상관없습니다. 저는 '내업로더' 라고 하겠습니다.
> 위치는 그대로 두시고 **만들기** 를 누릅니다.

**화면** — 생성 완료 알림, 프로젝트 선택 상태

> 잠깐 기다리면 만들어집니다. 만들어진 뒤에는
> 화면 위쪽에 **방금 만든 프로젝트 이름이 선택되어 있는지** 확인해 주세요.
> 다른 게 선택되어 있으면 눌러서 바꿔주셔야 합니다. 이거 놓치면 뒤에서 다 꼬입니다.

## 5. ★ 동의 화면 만들고 게시하기 · 2분

**화면** — 앱 이름, 이메일 입력

> 앱 이름은 아무거나 괜찮습니다. 이메일은 본인 이메일을 넣으시면 되고,
> 아래 개발자 연락처에도 같은 이메일을 넣고 계속 누르시면 됩니다.

**화면** — 범위 추가 → youtube.upload 검색 → 체크 → 업데이트

> 다음 화면에서 **범위 추가 또는 삭제** 를 누르시고,
> 검색창에 `youtube.upload` 이라고 입력합니다.
> 나온 항목을 체크하고 **업데이트** 를 누른 다음, 저장하고 계속을 눌러 끝까지 진행합니다.

**★ 함정 2 — 앱 게시**

**화면** — 동의 화면 첫 페이지의 '앱 게시' 버튼 확대 → 클릭 → 확인

> 자, 여기가 두 번째로 중요한 곳입니다.
> 다 하시고 나면 이 화면 첫 페이지에 **앱 게시** 버튼이 보입니다. 영어로는 PUBLISH APP 입니다.
>
> **이걸 꼭 눌러주세요.**
>
> 안 누르면 지금 상태가 '테스트' 로 남는데, 테스트 상태에서는
> **7일마다 로그인이 저절로 풀립니다.** 매주 다시 로그인해야 한다는 뜻이죠.
>
> 눌러서 '프로덕션' 으로 바꿔두시면 그럴 일이 없습니다.
> 본인만 쓰는 프로그램이라 구글 심사를 따로 받지 않아도 잘 동작합니다.

**자막** — `★ 앱 게시 안 하면 7일마다 로그인 풀림`

> 폴더에 영상 저장 → 자동 업로드 → 스튜디오에서 공개로 전환.
>
> 하루에 올릴 수 있는 개수는 구글이 정해둔 한도 때문에 **6개** 입니다.
> 넘긴 영상은 사라지지 않고 폴더에 기다리다가 다음 날 자동으로 올라갑니다.
>
> 설정하다 막히시면, 프로그램의 **시작하기** 탭 맨 아래에
> 오류 문구별 해결 방법이 정리되어 있으니 참고해 주세요.
>
> 감사합니다.

## 편집 체크리스트

- [ ] 클라이언트 ID · 보안 비밀번호 · 이메일 주소 모자이크
- [ ] ★ 세 구간에 강조 자막과 효과음
- [ ] 챕터 나누기 (유튜브 설명란에 타임스탬프)
- [ ] 설명란에 다운로드 주소
- [ ] 고정 댓글에 자주 막히는 3가지 요약

## 설명란 문구 (그대로 복사해서 쓰세요)

```
가라사대 업로더 — 폴더에 저장하면 유튜브에 자동 업로드

다운로드
https://github.com/beautifulahin/garasadae-uploader/releases

00:00 이런 프로그램입니다
00:20 프로그램 받아서 실행하기
01:20 왜 구글 설정이 필요한가
01:50 구글 클라우드 프로젝트 만들기
03:20 ★ 유튜브 API 켜기
04:20 ★ 동의 화면 만들고 앱 게시하기
06:20 ★ 열쇠 발급받기 (데스크톱 앱)
07:50 프로그램에 붙여넣고 연결
09:20 제대로 됐는지 확인
09:50 실제로 써보기

가장 많이 막히는 3가지
1. YouTube Data API v3 를 켜지 않음 → 로그인은 되는데 영상이 안 올라감
2. 동의 화면을 '앱 게시' 하지 않음 → 7일마다 로그인이 풀림
3. 클라이언트 유형을 '웹 애플리케이션' 으로 선택 → 액세스가 차단됨 오류
```
