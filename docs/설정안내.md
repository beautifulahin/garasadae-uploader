# 가라사대 업로더 설정 안내

유튜브 채널에 영상을 올려 주는 프로그램입니다. 영상을 채널 폴더에 넣고, 화면에서 **골라 담아 올립니다.**
**2.0.0 부터는 구글 로그인 열쇠가 프로그램에 들어 있어서, 구글 클라우드 설정 없이 로그인만 하면 됩니다.**

- 걸리는 시간: 약 3분 (내 구글 열쇠를 직접 만들어 쓰려면 부록 A · 약 10분)
- 준비물: 유튜브 채널이 있는 구글 계정

> 옛 버전(1.x)에서 자동으로 올라오신 분은 **[옛 버전에서 올라오신 분께](#옛-버전에서-올라오신-분께)** 를 먼저 보세요.
> 중간에 막히시면 맨 아래 **막혔을 때** 를 봐주세요.

---
## 1단계 · 프로그램 받기

### 🍎 맥이라면 — 한 줄 설치 (가장 쉽습니다 · 경고창이 안 뜹니다)

**응용 프로그램 → 유틸리티 → 터미널** 을 열고, 아래 한 줄을 붙여넣고 Enter 를 누르세요.

```
curl -fsSL https://beautifulahin.github.io/garasadae-uploader/install.sh | bash
```

받기 · 설치 · 실행까지 알아서 다 합니다. 1분이면 끝나고 브라우저에 설정 화면이 열립니다.
Apple 칩인지 Intel 칩인지도 알아서 가려 받으니 아래 표를 보실 필요가 없습니다.
**이렇게 하셨다면 2단계는 건너뛰고 [3단계](#3단계--구글-클라우드-프로젝트-만들기) 로 가시면 됩니다.**

> **왜 터미널인가요?**
> 브라우저로 받으면 맥이 「인터넷에서 받음」 표를 붙여서 보안 경고가 뜹니다.
> 터미널로 받으면 그 표가 안 붙어서 **경고창 자체가 나오지 않습니다.**
>
> **터미널이 뭔가요?** 검은 글자창입니다. 맥에 원래 들어 있습니다.
> 화면 오른쪽 위 돋보기(Spotlight)를 누르고 `터미널` 이라고 쳐도 열립니다.

### 🪟 윈도우 · 🍎 맥 (직접 받기)

아래 주소에서 본인 컴퓨터에 맞는 파일을 받습니다.

**https://github.com/beautifulahin/garasadae-uploader/releases**

| 내 컴퓨터 | 받을 파일 |
|---|---|
| 윈도우 10 / 11 | `garasadae-uploader-windows.zip` |
| 맥 (Apple 칩) | `garasadae-uploader-mac-apple-silicon.zip` |
| 맥 (Intel 칩) | `garasadae-uploader-mac-intel.zip` |

**내 맥이 어느 쪽인지 모르겠다면**
화면 왼쪽 위 사과 모양 → **이 Mac에 관하여** → **칩** 항목을 보세요.
`Apple M1`, `Apple M2` 처럼 적혀 있으면 Apple 칩, `Intel` 이라고 적혀 있으면 Intel 입니다.
2020년 이후에 산 맥은 대부분 Apple 칩입니다.

## 2단계 · 실행하기

> **맥에서 「한 줄 설치」로 하셨다면 이 단계는 이미 끝났습니다.** 3단계로 가세요.
> 아래는 zip 을 직접 받으신 분을 위한 안내입니다.

압축을 풀고 실행합니다. 처음 실행할 때만 보안 경고가 나옵니다.

### ⚠️ 첫 번째 주의 — 맥은 그냥 더블클릭하면 안 열립니다

더블클릭하면 *"'가라사대 업로더'을(를) 열지 않음"* 창이 뜨는데, 그 창에는 **열기 버튼이 없습니다.**
아래 ①부터 차례로 해 보세요. 위에 있을수록 쉽습니다.

**① 한 줄 설치 (가장 쉽습니다)**

지금이라도 터미널(**응용 프로그램 → 유틸리티 → 터미널**)을 열고 아래를 붙여넣으면
받기부터 실행까지 한 번에 끝나고, 경고창도 나오지 않습니다.

```
curl -fsSL https://beautifulahin.github.io/garasadae-uploader/install.sh | bash
```

브라우저로 받으면 맥이 「인터넷에서 받음」 표를 붙여서 경고가 뜨는데,
터미널로 받으면 그 표가 안 붙기 때문입니다.

**② 열기.command 를 더블클릭**

이미 zip 을 받으셨다면, 그 안에 같이 들어 있는 **`열기.command`** 를 더블클릭하세요.
검은 창이 뜨고 "열렸습니다" 가 나오면 된 것입니다. 아래 ③을 대신해 줍니다.

**③ 손으로 하기 (macOS 15 이상 · 요즘 맥은 대부분 여기)**

1. 앱을 **응용 프로그램** 폴더로 옮깁니다.
2. 한 번 더블클릭합니다. 「열지 않음」 창이 뜨면 **[완료]** 를 누릅니다.
   > ⚠️ **[휴지통으로 이동] 은 절대 누르지 마세요.** 앱이 지워집니다.
3. **시스템 설정 → 개인정보 보호 및 보안** 을 열고 아래로 내립니다.
   *"'가라사대 업로더'이(가) 차단되었습니다"* 옆의 **[무시하고 열기]** 를 누르고 암호를 넣습니다.
4. 다음부터는 그냥 더블클릭하면 열립니다.

**④ 옛 맥 (macOS 14 이하)**
1. 아이콘에서 **마우스 오른쪽 버튼** 클릭 (또는 Control 누른 채 클릭)
2. **열기** 선택
3. 경고창이 뜨면 한 번 더 **열기**

**윈도우**
1. 파란 경고창의 **추가 정보** 클릭
2. **실행** 클릭

공증(애플 심사)을 받지 않은 개인 배포 프로그램이라 나오는 안내입니다.
두 번째 실행부터는 그냥 열립니다.

### 맥이 폴더 접근을 물어보면

채널 폴더를 **문서·바탕화면·다운로드** 같은 곳에 두면 맥이 「…폴더에 접근하려고 합니다」 라고 한 번 물어봅니다.
**「허용」을 눌러 주세요.** 거부하면 그 폴더의 영상을 읽지 못해 아무것도 올릴 수 없습니다. 한 번만 누르면 다시 묻지 않습니다.

> 실수로 거부하셨다면 **시스템 설정 → 개인정보 보호 및 보안 → 파일 및 폴더** 에서 가라사대 업로더의 해당 폴더를 켜 주세요.
> 채널 폴더를 기본 위치(홈 폴더의 `가라사대업로더영상`)에 두면 이 질문이 거의 나오지 않습니다.

### 실행되면

- 브라우저에 화면이 자동으로 열립니다. (닫아도 프로그램은 계속 돕니다 · 다시 열려면 http://127.0.0.1:8777)
- 처음 켜면 **AI·쿠팡 파트너스 열쇠 창**이 한 번 뜹니다. 지금 안 넣어도 됩니다 — **나중에** 를 누르세요 (아래 5단계).
- 채널을 연결하면 홈 폴더의 `가라사대업로더영상/채널이름/` 폴더가 하나씩 생깁니다.

## 3단계 · 구글 계정 연결 (로그인 한 번)

1. 화면 위쪽의 **📺 채널** 탭(또는 **🚀 시작하기** 탭)을 엽니다.
2. **🔑 구글 계정 연결** 을 누릅니다. 브라우저에 구글 로그인 창이 열립니다.
3. **유튜브 채널이 있는 계정**을 고릅니다. 한 계정에 채널이 여럿이면 계정 선택 창의 **계정 전환**으로 다른 채널을 고를 수 있습니다.
4. 권한 세 가지를 허용합니다.
   - 영상 올리기 · 유튜브 읽기(채널 이름·배너·성적) · 영상 정보 고치기(비공개 → 공개 전환)
5. **연결되었습니다** 가 나오면 끝입니다. 채널 이름·배너·프로필 사진이 채널 탭에 나타납니다.

채널이 여럿이면 2~5 를 채널마다 되풀이합니다 (같은 채널을 두 번 연결해도 한 자리로 합쳐집니다).
컴퓨터 앞에 브라우저를 열 수 없는 기기라면 **코드 인증**(코드를 불러 주고 다른 기기에서 승인)을 쓰세요.

### "Google에서 확인하지 않은 앱" 이 나와도 정상입니다

개인이 배포하는 프로그램이라 구글의 앱 심사 표시가 없어서 나오는 화면입니다.

- 왼쪽 아래 **고급** 클릭
- 아래에 나오는 **(앱 이름)(으)로 이동** 클릭

> ⚠️ 구글 쪽 사정으로 이 기본 열쇠의 로그인이 제한되면(사용자 수 한도 등) 로그인이 막힐 수 있습니다.
> 그럴 때는 **부록 A** 로 내 열쇠를 만들어 쓰면 됩니다. 내 열쇠로 연결한 채널은 그 열쇠만 계속 씁니다.

## 4단계 · 영상 올리기

1. **📺 채널** 탭에서 채널마다 폴더를 확인합니다. 다른 폴더를 쓰려면 폴더를 다시 고르면 됩니다 (채널 이름이 적힌 표식이 새겨져서, 폴더가 다른 채널 것으로 바뀌는 사고를 막습니다).
2. 올릴 영상을 그 폴더에 넣습니다. 화면에 **끌어다 놓아도** 됩니다.
3. **👀 감시 중** 탭의 영상 벽에 카드가 나옵니다. 올릴 영상의 **담기**를 누릅니다.
4. **올리기** 를 누르면 확인 창이 뜹니다. 제목·설명·해시태그와 올리는 시각을 보고 고칠 수 있습니다.
5. 확인 창에서 **올리기** 를 누르면 시작합니다. 영상은 먼저 **비공개**로 올라가고, **30분 뒤 유튜브의 심사 결과를 확인해 자동으로 공개**합니다.

- 올리는 일은 **항상 직접 누릅니다.** 새로고침·뒤로가기·북마크로는 올라가지 않습니다.
- 쇼츠(180초 이하 세로·정사각)와 롱폼은 영상을 읽어 **자동으로 가려서** 하루 편수·공개 간격을 따로 셉니다.
- 정한 시각에 올리려면 확인 창에서 시각을 정하세요 (**발사 대기** — 그 시각까지 이 컴퓨터가 보관했다가 올립니다).
- 올리기가 끝난 영상은 채널 설정에 따라 `업로드완료` 폴더로 옮기거나, 휴지통으로 보내거나, 그대로 둡니다 (지우지 않습니다).
- 같은 영상은 두 번 올라가지 않습니다.

### 제목·설명·해시태그는 어떻게 정해지나요

먼저 **화면에서 직접 고친 것**(영상 옆 같은 이름 `.txt`), 그다음 **쪽지(`.json`)**, 그다음 **AI 가 자동으로 지은 것**, 마지막으로 **파일 이름**입니다. 제목·설명·태그를 칸마다 따로 정합니다.

```
001_오늘의영상.mp4
001_오늘의영상.txt     ← 직접 고친 문안 (제목 / 설명 / 태그 칸)
001_오늘의영상.json    ← 쪽지: {"title": "…", "description": "…", "tags": ["…"], "publishAt": "2026-10-20T19:00:00+09:00", "thumbnail": "001_오늘의영상.jpg"}
```

## 5단계 · (선택) AI 와 쿠팡 파트너스 연결

처음 켜면 한 번 뜨는 창에서, 또는 화면 위의 **✨ AI 연결** · **🛒 쿠팡 파트너스 연결** 단추로 언제든 연결합니다. **둘 다 선택이고, 열쇠는 각자 자기 것**입니다.

**이 컴퓨터에 이미 있는 열쇠를 찾아 줍니다.** 창을 열면 환경변수·다른 도구가 둔 열쇠 파일·쉘 설정 파일 같은 알려진 자리를 **읽기만** 해서 찾고,
찾은 것을 가려서(`AIza…끝4자리`와 찾은 자리) 보여 주며 연결 시험을 합니다. 시험을 통과한 것만 **「이걸로 쓰기」** 를 한 번 눌러 연결합니다.
아무것도 바꾸거나 어디로 보내지 않고, 열쇠 전체 값은 화면에 나오지 않습니다. 못 찾았으면 직접 붙여넣으세요.

- **AI (제목·설명·해시태그 자동 작성)** — [Google AI Studio](https://aistudio.google.com/apikey) 에서 무료로 열쇠(`AIza…`)를 만듭니다.
  문안이 없는 영상은 올리기 직전에 영상 내용과 **내 채널의 말투**(최근·잘된 영상, 채널마다 정한 앞·뒤 글과 늘 넣을 해시태그)를 보고 지어 넣습니다.
  쇼츠와 롱폼이 다르게 지어지고, 길이·글자 규칙을 통과한 것만 쓰입니다. 연결하면 바로 켜집니다. 영상 하나에 20~30초쯤 더 걸리고, 안 되면 파일 이름 제목으로 그냥 올라갑니다.
  > ⚠️ 켜면 올리려는 영상이 **본인의 구글 AI 스튜디오 계정으로 한 번 올라갔다가 곧바로 지워집니다** (구글이 영상을 봐야 제목을 지을 수 있습니다). 끄면 아무것도 올라가지 않습니다.
- **쿠팡 파트너스 (상품 링크 자동 넣기)** — 쿠팡 파트너스의 Access Key · Secret Key 를 넣습니다 ([partners.coupang.com](https://partners.coupang.com) → 마케팅 도구 → 오픈 API).
  영상 소재에 맞는 상품을 골라 설명 끝에 1~3개 링크와 파트너스 고지문을 붙입니다. 관련 상품이 없으면(뉴스·정치 등) 넣지 않고, 쿠팡이 안 되어도 올리기는 멈추지 않습니다.
  채널마다 켜고 끄기·하위 ID 를 정할 수 있고, 올리기 전에 어떤 링크가 붙는지 미리 볼 수 있습니다. 설명에 사람이 직접 넣은 링크가 있으면 그것이 먼저입니다.

## 부록 A · 내 구글 열쇠를 직접 만들어 쓰기 (선택)

> **이 단계는 필요한 분만 하세요.** 기본 열쇠로 로그인이 되면 건너뛰어도 됩니다.
> 내 열쇠를 쓰면 **하루 업로드 한도를 채널(프로젝트)마다 따로** 받고, 로그인이 풀리는 일이 줄어듭니다.
> 이 열쇠는 내 컴퓨터에만 저장되며 프로그램을 만든 사람도 볼 수 없습니다.
>
> **쓰는 법:** 아래 순서로 열쇠(클라이언트 ID·비밀번호, 또는 `client_secret.json` 파일)를 받은 뒤, 📺 채널 탭 → 그 채널의 **전용 열쇠**에
> 파일을 끌어다 놓거나 ID·비밀번호를 붙여넣고 **🔑 구글 계정 연결** 을 누르세요. 그 채널은 그 열쇠로만 갱신됩니다.
> (코드 인증까지 쓰려면 같은 프로젝트에서 「TV 및 입력 제한 기기」 유형 열쇠도 만들어 `device_secret.json` 로 넣습니다.)

### A-1 · 구글 클라우드 프로젝트 만들기

> **왜 필요한가요?**
> 구글은 프로그램이 유튜브에 영상을 올릴 때 누구 권한으로 올리는지를 반드시 확인합니다.
> 그래서 내 계정 전용 열쇠를 하나 만들어야 합니다.
> 이 열쇠는 내 컴퓨터에만 저장되며, 프로그램을 만든 사람도 볼 수 없습니다.
> 각자 만들어야 하루 업로드 개수도 각자 따로 받습니다.

1. 프로그램 화면에서 **시작하기** 탭을 누릅니다.
2. 1단계의 **프로젝트 만들기 열기** 버튼을 누릅니다.
3. **유튜브 채널이 있는 구글 계정**으로 로그인되어 있는지 확인합니다. (오른쪽 위에서 확인)
4. 프로젝트 이름은 아무거나 넣습니다. (예: `내업로더`)
5. **만들기** 를 누릅니다.

만든 뒤 **화면 위쪽에 방금 만든 프로젝트가 선택되어 있는지** 확인하세요.
다른 프로젝트가 선택되어 있으면 눌러서 바꿔야 합니다. 이걸 놓치면 뒤 단계가 전부 어긋납니다.

---

### A-2 · ⚠️ 유튜브 API 켜기 — 가장 많이 빠뜨리는 곳

**이 단계를 건너뛰면 영상이 하나도 올라가지 않습니다.**
그런데 로그인은 정상적으로 되기 때문에 다 됐다고 착각하기 쉽습니다.

1. 프로그램 2단계의 **API 사용 설정 열기** 버튼을 누릅니다.
2. 열린 페이지에서 **위쪽 프로젝트가 맞는지** 다시 확인합니다.
3. 파란색 **사용** 버튼을 누릅니다. (영어 화면이면 **ENABLE**)
4. 잠시 기다리면 버튼이 **관리**(**MANAGE**)로 바뀝니다.

> ✅ **버튼이 「사용」에서 「관리」로 바뀌면 성공입니다.** 이걸 확인하고 넘어가세요.

### A-3 · ⚠️ 동의 화면 만들고 게시하기

1. 프로그램 3단계의 **동의 화면 열기** 버튼을 누릅니다.
2. User Type 은 **외부** 를 선택하고 **만들기**.
3. 앱 이름은 아무거나, 이메일은 본인 이메일을 넣습니다. (개발자 연락처에도 같은 이메일)
4. 범위 단계에서 **범위 추가 또는 삭제** → 검색창에 `youtube.upload` 입력 → 체크 → **업데이트**
5. **저장하고 계속** 을 눌러 끝까지 진행합니다.

#### ⚠️ 두 번째 주의 — 앱 게시를 꼭 누르세요

동의 화면 첫 페이지에 **앱 게시**(**PUBLISH APP**) 버튼이 있습니다.

**이걸 누르지 않으면 7일마다 로그인이 저절로 풀립니다.**
매주 다시 로그인해야 한다는 뜻입니다.

눌러서 **프로덕션** 상태로 바꿔두세요.
본인만 쓰는 프로그램이라 구글 심사를 받지 않아도 정상 동작합니다.

> **게시(프로덕션 전환)와 심사(확인·verification)는 다른 것입니다.**
> 게시만 하면 되고, 심사는 신청하지 않아도 됩니다.
> 로그인할 때 뜨는 "확인되지 않은 앱" 경고는 위 3단계 방법대로 넘어가면 됩니다.

#### 앱 게시가 안 눌린다면

**「브랜딩」의 앱 도메인 세 칸은 비워 두세요.** 내 컴퓨터에서만 도는 프로그램이라
홈페이지 주소가 필요 없고, 주소만 적고 **승인된 도메인**을 등록하지 않으면
오히려 저장이 거부됩니다. **앱 로고도 올리지 마세요** — 구글 브랜드 심사 대상이 되어 게시가 막힙니다.
게시가 안 되는 가장 흔한 원인은 **개발자 연락처 이메일이 비어 있는 것**입니다.

그런데도 구글이 **세 칸을 채우라며** 게시를 막는 경우가 있습니다.
그때는 아래 네 줄을 **모두** 넣으세요. 이 프로그램의 공개 페이지입니다.

| 칸 | 넣을 값 |
|---|---|
| 애플리케이션 홈페이지 | `https://beautifulahin.github.io/garasadae-uploader/` |
| 애플리케이션 개인정보처리방침 링크 | `https://beautifulahin.github.io/garasadae-uploader/privacy.html` |
| 애플리케이션 서비스 약관 링크 | `https://beautifulahin.github.io/garasadae-uploader/terms.html` |
| 승인된 도메인 | `beautifulahin.github.io` (앞의 `https://` 없이) |

주소 세 개만 넣고 **승인된 도메인**을 빠뜨리면 거부됩니다. 네 칸을 함께 넣으세요.

**「도메인 소유권을 확인할 수 없습니다」가 뜬다면** 남의 도메인이라 구글이 막은 것입니다.
둘 중 하나를 고르세요.

1. **게시를 포기한다 (쉽습니다)** — 테스트 상태로 두어도 **업로드는 정상으로 됩니다.**
   대신 7일마다 프로그램의 **채널** 탭에서 **🔑 구글 계정 연결** 을 한 번 더 누르면 됩니다.
   기다리던 영상은 사라지지 않고 그대로 올라갑니다.
2. **내 주소를 만든다** — 깃허브 계정을 만들고 저장소를 하나 판 뒤
   **Settings → Pages** 를 켜고 `privacy.html`·`terms.html` 두 장을 올립니다.
   세 칸을 `본인아이디.github.io/...` 로, 승인된 도메인은 `본인아이디.github.io` 로 넣고,
   [Search Console](https://search.google.com/search-console) 에 **URL 접두어** 속성으로 소유확인을 합니다.

### A-4 · ⚠️ 열쇠(클라이언트 ID) 발급받기

1. 프로그램 4단계의 **사용자 인증 정보 열기** 버튼을 누릅니다.
2. **사용자 인증 정보 만들기** → **OAuth 클라이언트 ID**

#### ⚠️ 세 번째 주의 — 반드시 「데스크톱 앱」

애플리케이션 유형에서 **데스크톱 앱** 을 고르세요.

**「웹 애플리케이션」을 고르면 로그인할 때 "액세스가 차단됨" 오류가 납니다.**

3. **만들기** 를 누르면 **클라이언트 ID** 와 **클라이언트 보안 비밀번호** 가 나옵니다.
4. 두 개 모두 복사해 둡니다. (창을 닫아도 나중에 다시 볼 수 있습니다)

### A-5 · 이 열쇠로 채널 연결하기

1. 프로그램의 **📺 채널** 탭에서 채널 이름을 만듭니다. (이 이름으로 폴더가 만들어집니다)
2. 그 채널의 **전용 열쇠** 칸에 받은 `client_secret.json` 을 끌어다 놓거나, 클라이언트 ID 와 보안 비밀번호를 붙여넣습니다. (앞뒤 빈칸이 딸려오지 않았는지 확인하세요)
3. 그 채널의 **🔑 구글 계정 연결** 을 누르고, 구글 로그인 창에서 **그 채널이 있는 계정**을 고릅니다.
4. 권한을 허용하면 **연결되었습니다** 가 나옵니다. (위 3단계처럼 「확인하지 않은 앱」 안내가 나오면 **고급 → 이동**)
5. 채널 카드의 **🔍 연결 점검** 으로 채널 이름이 나오는지 확인합니다.

> 채널마다 프로젝트(열쇠)를 따로 만들면 하루 한도도 채널마다 따로 받습니다. 한 열쇠를 여러 채널이 같이 쓰면 한도를 **합쳐서** 나눠 씁니다.

## 사용하기

### 화면 둘러보기

- **👀 감시 중** — 영상 벽(올릴 차례 영상) · 장바구니 · 발사 대기 · 심사 대기 · 오늘 현황
- **📋 기록** — 올린 영상 목록, 날짜별·채널별 올린 편수
- **📊 성적** — 채널 성적 카드, 끌어올릴 영상, 구독자 증감, 수확 진행
- **📺 채널** — 채널 연결·폴더·채널별 설정(공개 칸·접두어·문안 규칙·쿠팡·AI)
- **⚙️ 설정** — 알림(텔레그램) · AI · 쿠팡 · 자동 시작 · 점검
- 위쪽 **신호등**은 문제 목록입니다. 눌러서 오류·작업불이행·경고를 보고, 고칠 수 있는 것은 단추로 고칩니다.
- 위쪽 **자물쇠**를 잠그면 올리기·공개가 모두 멈춥니다. **🌙 심야 금지**와 **⏸ 일시정지**도 있습니다.

### 영상을 휴지통으로 · 검토필요로

영상 카드에서 휴지통으로 보낼 수 있습니다 (지우지 않고 휴지통으로 — 되살릴 수 있습니다). 쇼츠 조건에 안 맞거나 다른 채널 영상이 섞인 것은 `검토필요` 폴더로 치워지고, 이유가 같은 이름의 메모에 남습니다.

### 하루에 몇 개까지?

구글이 **프로젝트마다** 하루 10,000점을 주고, 영상 하나 올리는 데 1,600점이 듭니다. 그래서 **프로젝트당 하루 6개**가 한도입니다.
한도를 넘긴 영상은 사라지지 않고 **다음 날로 자동으로 밀립니다.** 쇼츠·롱폼의 하루 편수와 공개 간격은 채널마다 따로 정할 수 있습니다.

### 창을 닫아도 계속 쓰려면

**⚙️ 설정** 에서 **컴퓨터 켤 때 자동 실행** 을 켜 두세요. 로그인할 때 화면 서버가 저절로 켜지고, **10분마다 심사 결과를 확인해 공개하는 작업**이 따로 돕니다.
(맥: 로그인 항목 두 개 · 윈도우: 시작 프로그램과 작업 스케줄러) 화면을 닫아도, 컴퓨터를 껐다 켜도 이어집니다.

### 명령줄

터미널에서 실행 파일 뒤에 한글 명령을 붙여 쓸 수 있습니다. 전체 목록은 `도움말`.

```
GarasadaeUploader 오늘            오늘 뭐가 올라갈지 본다 (아무것도 안 바꿈)
GarasadaeUploader 올려 --pick 영상.mp4 [--at "영상.mp4=2026-10-20 14:20"]
GarasadaeUploader 공개            심사 끝난 것을 공개로
GarasadaeUploader 문제            문제 목록          GarasadaeUploader 고침   자동으로 고칠 수 있는 것만
GarasadaeUploader 인증 --연속 3   한 구글 계정의 채널을 잇달아 연결
```

## 옛 버전에서 올라오신 분께

1.x 에서 자동으로 2.0.0 이 되었다면, **처음 켤 때 옛 자료가 새 방식으로 옮겨집니다.**
- 옮기기 전에 옛 설정·로그인 정보·올린 기록이 `데이터 폴더/백업/이행전_날짜_시각/` 에 **복사**됩니다. 옛 파일은 지우거나 덮지 않고 그대로 둡니다.
- 옮긴 뒤 옛 채널 수와 새 채널 수, 채널마다 로그인 정보·채널 ID·폴더, 올린 기록(예약 포함)이 모두 이어졌는지 **하나씩 확인**합니다.
- 하나라도 빠지면 **올리기·공개를 멈추고** 문제 목록에 빨간 줄이 뜹니다. 복사본 위치가 함께 나오고, **다시 옮기기** 를 누르면 이어서 다시 합니다. (옛 자료는 그대로입니다)
- 이미 로그인해 둔 채널은 **다시 로그인하지 않아도** 됩니다. 옛 열쇠로 받은 로그인은 그 열쇠 그대로 계속 씁니다.
- 로그인이 풀려도 채널은 지워지지 않습니다. 채널 카드에 **「다시 연결 필요」** 만 표시됩니다.

옛 버전에서 없어진 것: 폴더를 몇 초마다 훑어 바로 올리던 방식 · 「모든채널」 폴더와 「전체 업로드 대기」 · 첫 댓글 자동 달기 · 제목 자동 교체.

## 막혔을 때
### 실행했는데 아무 일도 안 일어납니다 (화면도 안 뜸)

프로그램이 아예 실행되지 않은 것입니다.
아래를 위에서부터 확인해 보세요.

**1. 압축을 풀었나요?**
zip 안에서 바로 실행하면 동작하지 않습니다.
**압축을 푼 뒤** 나온 파일을 실행해야 합니다.

**2. 보안 경고에서 멈추지 않았나요? (가장 흔한 원인)**

**윈도우** — 파란 창의 **추가 정보** → **실행** 을 눌러야 합니다. 그냥 확인을 누르면 실행되지 않습니다.

**맥** — 그냥 더블클릭하면 *"'가라사대 업로더'을(를) 열지 않음"* 창이 뜨고,
그 창에는 **열기 버튼이 없습니다.** 아래 ①부터 차례로 해 보세요.

**① 한 줄 설치로 다시 깔기 (가장 확실합니다)**

터미널(**응용 프로그램 → 유틸리티 → 터미널**)을 열고 아래를 붙여넣고 Enter 를 누르세요.
받기부터 실행까지 한 번에 끝나고, 경고창이 나오지 않습니다.

```
curl -fsSL https://beautifulahin.github.io/garasadae-uploader/install.sh | bash
```

브라우저로 받으면 맥이 「인터넷에서 받음」 표를 붙여서 경고가 뜨는데,
터미널로 받으면 그 표가 안 붙기 때문입니다.
이미 깔려 있던 앱은 지우지 않고 홈 폴더에 옮겨 둡니다.

**② 열기.command 를 더블클릭** — 받으신 압축 안에 같이 들어 있습니다. 아래 ③을 대신해 줍니다.

**③ 손으로 하기 (macOS 15 이상 · 요즘 맥은 대부분 여기)**

1. 앱을 **응용 프로그램** 폴더로 옮깁니다.
2. 한 번 더블클릭합니다. 「열지 않음」 창이 뜨면 **[완료]** 를 누릅니다.
   > ⚠️ **[휴지통으로 이동] 은 절대 누르지 마세요.** 앱이 지워집니다.
3. **시스템 설정 → 개인정보 보호 및 보안** 을 열고 아래로 내립니다.
   *"'가라사대 업로더'이(가) 차단되었습니다"* 옆의 **[무시하고 열기]** 를 누르고 암호를 넣습니다.
4. 다음부터는 그냥 더블클릭하면 열립니다.

**④ 옛 맥 (macOS 14 이하)** — 아이콘에 **오른쪽 클릭 → 열기** → 경고창에서 다시 **열기**.

공증(애플 심사)을 받지 않은 개인 배포 프로그램이라 나오는 안내입니다.
프로그램에 이상이 있는 것이 아닙니다.

**3. 맥에서 "손상되었기 때문에 열 수 없습니다" 가 나온다면**

터미널(응용 프로그램 → 유틸리티 → 터미널)을 열고 아래를 붙여넣고 Enter 를 누르세요.
그다음 다시 실행하면 됩니다.

```
xattr -cr ~/Downloads/가라사대\ 업로더.app
```

**4. 백신 프로그램이 지웠을 수 있습니다**

윈도우에서 알약·V3 등이 처음 보는 프로그램을 격리하는 경우가 있습니다.
백신의 격리 목록을 확인하고, 있으면 복원 후 예외로 등록해 주세요.

**5. 검은 창이 잠깐 떴다가 사라졌다면**

프로그램이 시작하다 오류가 난 것입니다.
그 창에 오류 내용이 남으니, 다시 실행해서 창에 적힌 내용을 알려주세요.

**6. 브라우저만 안 열렸다면**

정상 동작 중입니다. 브라우저를 직접 열고 아래 주소로 들어가세요.

```
http://127.0.0.1:8777
```

들어가지지 않으면(**"127.0.0.1에서 연결을 거부했습니다"**), 프로그램이 다른 번호로
옮겨 갔을 수 있습니다. 다른 프로그램이 8777 번을 쓰고 있을 때 그렇습니다.
`8778`, `8779` 도 시도해 보세요.

기록 탭에 `⚠️ 8777 번을 다른 프로그램이 쓰고 있어 …` 줄이 있으면 그 줄에 실제 주소가 적혀 있습니다.
**1.7.19 부터는** 옮겨 간 번호를 설정에 굳히지 않아, 8777 이 비면 다음에 켤 때 저절로 돌아옵니다.

### "액세스가 차단됨" 이 나옵니다

화면에 함께 나오는 **작은 글씨 한 줄**을 보세요.

| 나오는 문구 | 원인과 해결 |
|---|---|
| 앱이 Google 인증 절차를 완료하지 않았습니다 (오류 403) | 내 열쇠(부록 A)를 쓰는 중이고 동의 화면이 **테스트** 상태입니다. 부록 A-3 의 **앱 게시** 를 누르세요. 또는 테스트 사용자에 본인 이메일을 추가하세요. |
| 이 앱의 요청이 잘못되었습니다 (오류 400 redirect_uri_mismatch) | 내 열쇠의 유형이 **데스크톱 앱** 이 아닙니다. 부록 A-4 를 다시 하세요. |
| 오류 401 invalid_client | 클라이언트 ID 또는 비밀번호가 잘못 붙여넣어졌습니다. 앞뒤 공백을 확인하세요. |
| 관리자가 액세스를 차단했습니다 | 회사·학교 계정입니다. 개인 구글 계정으로 하세요. |

### 로그인은 됐는데 영상이 안 올라갑니다

내 열쇠(부록 A)를 쓰고 있다면 **A-2 YouTube API 켜기** 를 빠뜨렸을 가능성이 가장 높습니다. 프로그램에 나오는 **구글 설정 화면 열기** 단추로 **사용** 을 켜고, 1~2분 뒤 다시 시도하세요.
기본 열쇠를 쓰고 있다면 문제 목록(위쪽 신호등)의 설명을 따르세요.

### 채널 카드에 「다시 연결 필요」 가 떴습니다

구글이 그 채널의 로그인을 거절했습니다(만료·취소·비밀번호 변경). **채널은 지워지지 않았고** 폴더·기록도 그대로입니다. 그 채널의 **🔑 구글 계정 연결** 을 한 번 더 누르면 됩니다.
내 열쇠(부록 A)의 동의 화면이 **테스트** 상태면 7일마다 이렇게 풀립니다 — 부록 A-3 의 **앱 게시** 로 막을 수 있습니다.

### "채널을 찾을 수 없습니다" 라고 나옵니다

로그인한 구글 계정에 유튜브 채널이 없습니다. 유튜브에서 채널을 먼저 만드세요.

### 영상을 폴더에 넣었는데 카드가 안 나옵니다

- **채널 폴더**에 넣으셨는지 확인하세요. 채널 탭에서 각 채널의 폴더 위치를 볼 수 있습니다.
- 영상 파일 형식인지 확인하세요 (mp4 · mov · m4v · webm).
- 문제 목록에 「폴더 짝이 맞지 않습니다」가 떠 있지 않은지 보세요. 폴더의 표식이 다른 채널을 가리키면 올리기를 막습니다.

### 위쪽에 빨간 줄 「옛 판 자료를 새 판으로 옮긴 결과를 확인하지 못해 …」 가 떴습니다

옛 버전에서 올라오신 분께 나올 수 있는 안내입니다. 복사본 위치와 빠진 것이 함께 나옵니다. **다시 옮기기** 를 눌러 보세요. 계속 같으면 알려 주세요 — 옛 자료와 복사본은 그대로 있으니 잃은 것은 없습니다.

### 음악 넣기를 눌렀더니 "오류가 발생했습니다" 가 뜹니다

브라우저에 **다른 구글 계정이 함께 로그인**되어 있을 때 생깁니다.
유튜브 스튜디오는 로그인된 계정을 따라가기 때문에, 채널 주인이 아닌 계정으로 열리면 오류가 납니다.
다른 구글 계정 창을 모두 닫거나 로그아웃한 뒤 다시 눌러 보세요.

### 그래도 안 되면

프로그램 **기록** 탭 아래쪽에 로그가 있습니다. 그 내용을 알려주시면 원인을 찾을 수 있습니다.
