# 가라사대 업로더 설정 안내

폴더에 영상을 저장하면 유튜브에 자동으로 올려주는 프로그램입니다.
**처음 한 번만** 아래 설정을 하시면, 그 뒤로는 폴더에 넣기만 하면 됩니다.

- 걸리는 시간: 약 10분
- 준비물: 유튜브 채널이 있는 구글 계정

> 중간에 막히시면 맨 아래 **막혔을 때** 를 봐주세요.
> 자주 막히는 곳 세 군데는 본문에 ⚠️ 로 표시해 두었습니다.

---

## 1단계 · 프로그램 받기

아래 주소에서 본인 컴퓨터에 맞는 파일을 받습니다.

**https://github.com/beautifulahin/garasadae-uploader/releases**

| 내 컴퓨터 | 받을 파일 |
|---|---|
| 윈도우 10 / 11 | `garasadae-uploader-windows.zip` |
| 맥 (Apple 칩) | `garasadae-uploader-mac-apple-silicon.zip` |
| 맥 (Intel 칩) | `garasadae-uploader-mac-intel.zip` |

**내 맥이 어느 쪽인지 모르겠다면**
화면 왼쪽 위 사과 모양 → **이 Mac에 관하여** → **칩** 항목을 보세요.
`Apple M1`, `Apple M2` 처럼 적혀 있으면 Apple 칩, `Intel` 이라고 적혀 있으면 Intel 입니다.
2020년 이후에 산 맥은 대부분 Apple 칩입니다.

---

## 2단계 · 실행하기

압축을 풀고 실행합니다. 처음 실행할 때만 보안 경고가 나옵니다.

### ⚠️ 첫 번째 주의 — 그냥 더블클릭하면 안 열립니다

**맥**
1. 아이콘에서 **마우스 오른쪽 버튼** 클릭 (또는 Control 누른 채 클릭)
2. **열기** 선택
3. 경고창이 뜨면 한 번 더 **열기**

**윈도우**
1. 파란 경고창의 **추가 정보** 클릭
2. **실행** 클릭

인증 비용을 들이지 않은 개인 배포 프로그램이라 나오는 안내입니다.
두 번째 실행부터는 그냥 열립니다.

### 「데스크탑 폴더에 접근하려고 합니다」 창이 뜨면

**「허용」을 눌러 주세요.**

바탕화면에 `업로드대기` 폴더를 만들고 그 안을 지켜보려면 이 권한이 필요합니다.
거부하면 폴더를 만들지 못해 아무 영상도 올라가지 않습니다.
맥이 모든 프로그램에 요구하는 절차이고, 한 번만 누르면 다시 묻지 않습니다.

> 실수로 거부하셨다면 **시스템 설정 → 개인정보 보호 및 보안 → 파일 및 폴더** 에서
> 가라사대 업로더의 **데스크탑 폴더** 를 켜 주세요.

### 실행되면

- 브라우저에 설정 화면이 자동으로 열립니다.
- 바탕화면에 **업로드대기** 폴더가 저절로 만들어집니다. (직접 만들 필요 없습니다)
- 채널을 등록하면 그 안에 **채널 이름으로 폴더가 하나씩** 생깁니다.

---

## 3단계 · 구글 클라우드 프로젝트 만들기

> **왜 필요한가요?**
> 구글은 프로그램이 유튜브에 영상을 올릴 때 누구 권한으로 올리는지를 반드시 확인합니다.
> 그래서 내 계정 전용 열쇠를 하나 만들어야 합니다.
> 이 열쇠는 내 컴퓨터에만 저장되며, 프로그램을 만든 사람도 볼 수 없습니다.
> 각자 만들어야 하루 업로드 개수도 각자 따로 받습니다.

1. 프로그램 화면에서 **시작하기** 탭을 누릅니다.
2. 1단계의 **프로젝트 만들기 열기** 버튼을 누릅니다.
3. **유튜브 채널이 있는 구글 계정**으로 로그인되어 있는지 확인합니다. (오른쪽 위에서 확인)
4. 프로젝트 이름은 아무거나 넣습니다. (예: `내업로더`)
5. **만들기** 를 누릅니다.

만든 뒤 **화면 위쪽에 방금 만든 프로젝트가 선택되어 있는지** 확인하세요.
다른 프로젝트가 선택되어 있으면 눌러서 바꿔야 합니다. 이걸 놓치면 뒤 단계가 전부 어긋납니다.

---

## 4단계 · ⚠️ 유튜브 API 켜기 — 가장 많이 빠뜨리는 곳

**이 단계를 건너뛰면 영상이 하나도 올라가지 않습니다.**
그런데 로그인은 정상적으로 되기 때문에 다 됐다고 착각하기 쉽습니다.

1. 프로그램 2단계의 **API 사용 설정 열기** 버튼을 누릅니다.
2. 열린 페이지에서 **위쪽 프로젝트가 맞는지** 다시 확인합니다.
3. 파란색 **사용** 버튼을 누릅니다. (영어 화면이면 **ENABLE**)
4. 잠시 기다리면 버튼이 **관리**(**MANAGE**)로 바뀝니다.

> ✅ **버튼이 「사용」에서 「관리」로 바뀌면 성공입니다.** 이걸 확인하고 넘어가세요.

---

## 5단계 · ⚠️ 동의 화면 만들고 게시하기

1. 프로그램 3단계의 **동의 화면 열기** 버튼을 누릅니다.
2. User Type 은 **외부** 를 선택하고 **만들기**.
3. 앱 이름은 아무거나, 이메일은 본인 이메일을 넣습니다. (개발자 연락처에도 같은 이메일)
4. 범위 단계에서 **범위 추가 또는 삭제** → 검색창에 `youtube.upload` 입력 → 체크 → **업데이트**
5. **저장하고 계속** 을 눌러 끝까지 진행합니다.

### ⚠️ 두 번째 주의 — 앱 게시를 꼭 누르세요

동의 화면 첫 페이지에 **앱 게시**(**PUBLISH APP**) 버튼이 있습니다.

**이걸 누르지 않으면 7일마다 로그인이 저절로 풀립니다.**
매주 다시 로그인해야 한다는 뜻입니다.

눌러서 **프로덕션** 상태로 바꿔두세요.
본인만 쓰는 프로그램이라 구글 심사를 받지 않아도 정상 동작합니다.

---

## 6단계 · ⚠️ 열쇠(클라이언트 ID) 발급받기

1. 프로그램 4단계의 **사용자 인증 정보 열기** 버튼을 누릅니다.
2. **사용자 인증 정보 만들기** → **OAuth 클라이언트 ID**

### ⚠️ 세 번째 주의 — 반드시 「데스크톱 앱」

애플리케이션 유형에서 **데스크톱 앱** 을 고르세요.

**「웹 애플리케이션」을 고르면 로그인할 때 "액세스가 차단됨" 오류가 납니다.**

3. **만들기** 를 누르면 **클라이언트 ID** 와 **클라이언트 보안 비밀번호** 가 나옵니다.
4. 두 개 모두 복사해 둡니다. (창을 닫아도 나중에 다시 볼 수 있습니다)

---

## 7단계 · 채널 등록하고 연결하기

1. 프로그램의 **채널** 탭으로 갑니다.
2. **➕ 채널 추가** 에 채널 이름을 적습니다. (이 이름으로 폴더가 만들어집니다)
3. 아래 두 칸에 각각 붙여넣습니다.
   - 클라이언트 ID
   - 클라이언트 보안 비밀번호
   - 앞뒤에 빈칸이 딸려오지 않았는지 확인하세요.
4. **➕ 채널 만들기** 를 누릅니다.
5. 만들어진 채널의 **🔑 구글 계정 연결** 을 누릅니다.
6. 구글 로그인 창에서 **그 채널이 있는 계정**을 선택합니다.

### "Google에서 확인하지 않은 앱" 이 나와도 정상입니다

본인이 방금 직접 만든 앱이라 나오는 화면입니다.

- 왼쪽 아래 **고급** 클릭
- 아래에 나오는 **(앱 이름)(으)로 이동** 클릭

권한을 허용하면 **연결되었습니다** 화면이 나오고, 프로그램 오른쪽 위에 채널 이름이 표시됩니다.

---

## 8단계 · 제대로 됐는지 확인

채널 카드의 **🔍 연결 점검** 버튼을 누릅니다.

채널 이름이 나오면 전부 정상입니다.
오류가 나오면 화면에 해결 버튼이 함께 나오니 눌러서 처리하시면 됩니다.

---

## 채널을 여러 개 쓰려면

채널마다 폴더가 하나씩 생깁니다. **그 폴더에 넣으면 그 채널로 올라갑니다.**

```
바탕화면/업로드대기/
├── 모든채널/   ← 여기 넣으면 모든 채널에 각각 올라갑니다
├── 채널1/     ← 여기 넣으면 채널1 로
├── 채널2/     ← 여기 넣으면 채널2 로
└── 채널3/
```

### 같은 영상을 여러 채널에 올리려면

**모든채널** 폴더에 한 번만 넣으면 됩니다. 프로그램이 채널마다 복사해서 각각 올립니다.
원본은 `모든채널/_완료` 에 보관되므로 두 번 올라가지 않습니다.
(채널이 둘 이상일 때 이 폴더가 생깁니다)

> 완전히 같은 영상을 여러 채널에 올리면 유튜브가 **재사용된 콘텐츠**로 볼 수 있습니다.
> 채널마다 제목 앞뒤 문구와 설명을 다르게 두시면 안전합니다. 채널 설정에서 정할 수 있습니다.

채널을 추가하려면 **3단계부터 7단계를 채널마다 다시** 하시면 됩니다.
구글 계정이 다르면 그 계정으로 로그인해서 프로젝트를 만드세요.

> ### 왜 채널마다 따로 만들어야 하나요?
> 하루 업로드 한도(6개)는 채널이 아니라 **구글 프로젝트마다** 주어집니다.
>
> | 방식 | 하루에 올릴 수 있는 개수 |
> |---|---|
> | 채널 3개가 프로젝트 하나를 같이 씀 | 3채널 **합쳐서 6개** |
> | 채널마다 프로젝트 따로 | **채널당 6개 · 합계 18개** |
>
> 자주 올리는 채널이라면 반드시 따로 만드세요.
> 가끔만 올리는 채널이라면 채널 추가에서 **기존 채널과 같이 쓰기** 를 골라 설정을 건너뛸 수 있습니다.

## 이제 사용하기

채널 폴더에 영상 파일을 저장하면 끝입니다.
프로그램 화면에 **끌어다 놓아도** 됩니다. (채널이 여러 개면 어느 채널로 보낼지 고를 수 있습니다)

- 파일 저장이 완전히 끝날 때까지 기다렸다가 올리므로, 영상 편집 프로그램에서 **내보내기 중에 넣어도 안전**합니다.
- 제목은 파일 이름이 그대로 들어갑니다. 올라가기 전에 화면에서 고칠 수 있습니다.
- 올라간 영상은 **비공개** 상태입니다. 유튜브 스튜디오에서 확인 후 공개로 바꾸세요.
- 업로드가 끝난 파일은 설정에 따라 `_완료` 폴더로 옮겨지거나 삭제됩니다.

### 음악을 넣으려면

업로드가 끝나면 **「음악을 넣으시겠어요?」** 창이 뜹니다.
「음악 넣기」를 누르면 그 영상의 유튜브 스튜디오 **편집기**가 열립니다. 이어서 이렇게 하시면 됩니다.

1. 목록에서 **♪ 오디오** 오른쪽의 **＋** 를 누릅니다
2. 무료 음악 목록이 나오면 곡을 고릅니다
3. **저장** 을 누릅니다

> 유튜브가 음악 화면으로 바로 들어가는 주소를 제공하지 않아, 편집기까지만 열어 드립니다.

> ⚠️ **누르기 전에 다른 구글 계정 창을 모두 닫아 주세요.**
> 브라우저에 여러 구글 계정이 함께 로그인되어 있으면 스튜디오가 어느 계정인지 헷갈려
> **「오류가 발생했습니다」** 가 뜹니다. 계정 창을 정리하면 정상적으로 열립니다.

매번 묻는 것이 번거로우면 창 아래의 **앞으로 항상 열기** 또는 **다시 묻지 않기** 를 누르세요.
설정 탭에서 언제든 바꿀 수 있습니다.

### 창을 닫아도 계속 쓰려면

설정 탭에서 **컴퓨터 켤 때 자동 실행** 을 켜두세요.
창을 닫아도, 컴퓨터를 껐다 켜도 계속 감시합니다.

### 화면을 다시 열려면

브라우저에서 **http://127.0.0.1:8777** 로 접속하거나, 프로그램을 다시 실행하세요.

### 하루에 몇 개까지?

구글이 **프로젝트마다** 하루 10,000점을 주고, 영상 하나 올리는 데 1,600점이 듭니다.
그래서 **프로젝트당 하루 6개**가 한도입니다.

채널마다 프로젝트를 따로 만들었다면 **채널당 6개씩** 올릴 수 있습니다.

한도를 넘긴 영상은 사라지지 않습니다. 폴더에서 기다리다가 **다음 날 자동으로** 올라갑니다.
채널이 여러 개면 한 채널이 한도를 다 써도 **다른 채널은 계속 올라갑니다.**

## 막혔을 때

### 실행했는데 아무 일도 안 일어납니다 (창도 안 뜨고 폴더도 안 생김)

프로그램이 아예 실행되지 않은 것입니다. 실행만 되면 폴더는 무조건 생깁니다.
아래를 위에서부터 확인해 보세요.

**1. 압축을 풀었나요?**
zip 안에서 바로 실행하면 동작하지 않습니다.
**압축을 푼 뒤** 나온 파일을 실행해야 합니다.

**2. 보안 경고에서 멈추지 않았나요? (가장 흔한 원인)**

- **윈도우** — 파란 창의 **추가 정보** → **실행** 을 눌러야 합니다. 그냥 확인을 누르면 실행되지 않습니다.
- **맥** — 그냥 더블클릭하면 열리지 않습니다. **오른쪽 클릭 → 열기** → 경고창에서 다시 **열기**.

**3. 맥에서 "손상되었기 때문에 열 수 없습니다" 가 나온다면**

터미널(응용 프로그램 → 유틸리티 → 터미널)을 열고 아래를 붙여넣고 Enter 를 누르세요.
그다음 다시 실행하면 됩니다.

```
xattr -cr ~/Downloads/가라사대\ 업로더.app
```

**4. 맥 최신 버전에서 열기 항목이 없다면**

한 번 실행을 시도한 뒤 **시스템 설정 → 개인정보 보호 및 보안** 으로 갑니다.
아래로 내리면 *"'가라사대 업로더'이(가) 차단되었습니다"* 라는 문구와 함께
**그래도 열기** 버튼이 있습니다. 그걸 누르세요.

**5. 백신 프로그램이 지웠을 수 있습니다**

윈도우에서 알약·V3 등이 처음 보는 프로그램을 격리하는 경우가 있습니다.
백신의 격리 목록을 확인하고, 있으면 복원 후 예외로 등록해 주세요.

**6. 검은 창이 잠깐 떴다가 사라졌다면**

프로그램이 시작하다 오류가 난 것입니다.
그 창에 오류 내용이 남으니, 다시 실행해서 창에 적힌 내용을 알려주세요.

**7. 폴더는 생겼는데 브라우저만 안 열렸다면**

정상 동작 중입니다. 브라우저를 직접 열고 아래 주소로 들어가세요.

```
http://127.0.0.1:8777
```

들어가지지 않으면, 프로그램이 다른 번호로 옮겨 갔을 수 있습니다.
`8778`, `8779` 도 시도해 보세요.

### "액세스가 차단됨" 이 나옵니다

화면에 함께 나오는 **작은 글씨 한 줄**을 보세요.

| 나오는 문구 | 원인과 해결 |
|---|---|
| 앱이 Google 인증 절차를 완료하지 않았습니다 (오류 403) | 동의 화면이 아직 **테스트** 상태입니다. 5단계의 **앱 게시** 를 누르세요. 또는 테스트 사용자에 본인 이메일을 추가하세요. |
| 이 앱의 요청이 잘못되었습니다 (오류 400 redirect_uri_mismatch) | 클라이언트 유형이 **데스크톱 앱** 이 아닙니다. 6단계를 다시 하세요. |
| 오류 401 invalid_client | 클라이언트 ID 또는 비밀번호가 잘못 붙여넣어졌습니다. 앞뒤 공백을 확인하세요. |
| 관리자가 액세스를 차단했습니다 | 회사·학교 계정입니다. 개인 구글 계정으로 하세요. |

### 로그인은 됐는데 영상이 안 올라갑니다

**4단계 API 사용 설정**을 빠뜨렸을 가능성이 가장 높습니다.
프로그램 화면에 나오는 **구글 설정 화면 열기** 버튼을 눌러 **사용** 을 켜고, 1~2분 뒤 **지금 다시 시도** 를 누르세요.

### 일주일쯤 지나니 로그인이 풀렸습니다

동의 화면이 **테스트** 상태입니다. 5단계의 **앱 게시** 를 누르세요.

### "채널을 찾을 수 없습니다" 라고 나옵니다

로그인한 구글 계정에 유튜브 채널이 없습니다. 유튜브에서 채널을 먼저 만드세요.

### 영상을 폴더에 넣었는데 반응이 없습니다

- 프로그램이 실행 중인지 확인하세요. (브라우저에서 http://127.0.0.1:8777 접속)
- **채널 폴더**에 넣으셨는지 확인하세요. 채널 탭에서 각 채널의 폴더 위치를 볼 수 있습니다.
- 그 채널이 **사용 중**인지 확인하세요. (채널 설정의 「이 채널 사용」)
- 영상 파일 형식인지 확인하세요. (mp4, mov, avi, webm, mkv 등)

### 한 채널만 안 올라갑니다

그 채널의 카드에 빨간 안내가 떠 있는지 보세요. 채널마다 구글 설정이 다르기 때문에
한 채널만 API 설정이 빠졌거나 로그인이 풀렸을 수 있습니다.
채널 탭에서 그 채널의 **🔍 연결 점검** 을 눌러 확인하세요.

### 음악 넣기를 눌렀더니 "오류가 발생했습니다" 가 뜹니다

브라우저에 **다른 구글 계정이 함께 로그인**되어 있을 때 생깁니다.
유튜브 스튜디오는 로그인된 계정을 따라가기 때문에, 채널 주인이 아닌 계정으로 열리면 오류가 납니다.

다른 구글 계정 창을 모두 닫거나 로그아웃한 뒤 다시 눌러 보세요.

### 그래도 안 되면

프로그램 **기록** 탭 아래쪽에 로그가 있습니다. 그 내용을 알려주시면 원인을 찾을 수 있습니다.
