⚙️ 최초 1회 설정
유튜브 업로드는 API 키만으로는 불가능하고 OAuth 2.0 로그인이 필요합니다. 아래 순서대로 5분이면 끝납니다.

⚠️ 반드시 localhost 로 실행하세요

구글 로그인은 file:// 주소에서 동작하지 않습니다. 터미널에서 아래를 실행한 뒤 http://localhost:8000 으로 접속하세요.
cd /Users/kimtaeyun/가라사대/youtube-uploader
python3 -m http.server 8000

1️⃣ Google Cloud 프로젝트 · API 켜기

  1. console.cloud.google.com 접속 → 프로젝트 생성
  2. 「API 및 서비스」 → 「라이브러리」 → YouTube Data API v3 검색 → 사용 설정

2️⃣ OAuth 동의 화면

  1. 「OAuth 동의 화면」 → User Type 외부 선택
  2. 앱 이름 / 지원 이메일 입력
  3. 범위(Scope)에 .../auth/youtube.upload 추가
  4. 테스트 사용자에 본인 구글 계정 추가 ← 이거 빠뜨리면 로그인 시 403

3️⃣ OAuth 클라이언트 ID 발급

  1. 「사용자 인증 정보」 → 「사용자 인증 정보 만들기」 → OAuth 클라이언트 ID
  2. 유형: 웹 애플리케이션
  3. 승인된 JavaScript 원본에 정확히 추가:
    http://localhost:8000
  4. 생성된 ...apps.googleusercontent.com 을 복사해 상단 입력창에 붙여넣고 저장 → 로그인

📊 API 쿼터 참고

  • 기본 일일 쿼터: 10,000 units
  • 영상 업로드 1건 = 1,600 units → 하루 약 6건
  • 썸네일 설정 1건 = 50 units
  • 더 필요하면 Google에 쿼터 증액 신청

🔐 테스트 모드 주의

  • 앱이 테스트 상태면 업로드된 영상은 비공개로 고정될 수 있습니다.
  • 공개로 올리려면 Google의 앱 검수(감사)를 받아야 합니다.
  • 개인 용도라면 비공개로 올린 뒤 YouTube Studio에서 공개로 바꾸는 방식을 권합니다.
