1. 프로그램의 성격

가라사대 업로더(이하 "프로그램")는 사용자의 컴퓨터에서 지정한 폴더를 감시하여 영상을 사용자 본인의 유튜브 채널에 올려 주는 무료 데스크톱 프로그램입니다. 개발자가 운영하는 서버나 계정 서비스는 없습니다.

2. 이용 조건

  • 프로그램은 무료이며, 사용자는 개인적·상업적 목적으로 자유롭게 사용할 수 있습니다.
  • 사용자는 본인이 권한을 가진 유튜브 채널에만 프로그램을 연결해야 합니다.
  • 사용자는 업로드하는 콘텐츠에 대해 저작권·초상권 등 모든 권리와 책임을 집니다.
  • 프로그램을 유튜브 서비스 약관·커뮤니티 가이드·Google API 서비스 약관을 위반하는 데 사용해서는 안 됩니다.

3. 구글 서비스 이용

프로그램은 YouTube Data API 를 사용합니다. 이에 따라 사용자는 YouTube 서비스 약관과 Google 개인정보처리방침에도 동의하는 것입니다. 구글 계정 연결은 사용자가 구글 계정 설정에서 언제든 철회할 수 있습니다.

4. 업로드 한도와 동작

  • 구글이 정한 API 한도(프로젝트당 하루 약 6편)에 따라 그날 올리지 못한 영상은 다음 날 자동으로 이어서 올라갑니다.
  • 영상은 기본적으로 비공개로 올라가며, 공개 여부는 사용자가 정합니다.

5. 보증의 부인과 책임의 제한

프로그램은 "있는 그대로" 제공됩니다. 개발자는 프로그램의 무오류·중단 없음을 보증하지 않으며, 프로그램 사용으로 발생한 업로드 실패·중복 업로드·계정 제재·데이터 손실 등 어떠한 손해에 대해서도 법이 허용하는 범위에서 책임을 지지 않습니다. 중요한 영상은 원본을 따로 보관하시기 바랍니다.

6. 배포와 소스

프로그램과 소스는 GitHub에서 배포되며, 저장소에 적힌 라이선스를 따릅니다.

7. 약관의 변경

약관이 바뀌면 이 페이지에 시행일과 함께 갱신합니다.
