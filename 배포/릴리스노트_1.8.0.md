# 가라사대 업로더 1.8.0

받은 의견 두 건을 고쳤고, 오래 미뤄 둔 것 하나를 넣었습니다. 알려 주셔서 고맙습니다.

## 🤖 제목·설명을 영상 보고 지어 줍니다 (새 기능)

> ### ⚠️ 이 기능은 **안 쓰셔도 됩니다**
> **기본값은 꺼짐**입니다. 아무것도 안 하시면 지금까지와 **똑같이** 동작합니다 —
> 파일 이름이 제목이 되고, 설명은 채널 기본값이 붙습니다.
> **열쇠를 넣는 것도 선택**이고, 안 넣으면 이 기능은 아예 돌지 않습니다.
> 업데이트했다고 뭔가 달라지거나 새로 설정할 것은 **없습니다.**

여태 제목은 **파일 이름 그대로**였습니다. 이제 설정에서 켜 두면 올리기 직전에
**영상을 보고** 제목·설명·해시태그를 지어 넣습니다.

- **쓰고 싶을 때만** 설정 탭 → **🤖 제목·설명 자동으로 짓기** 를 켜고,
  [Google AI Studio](https://aistudio.google.com/apikey) 에서 받은 **본인 열쇠**를 넣습니다. 무료로 받을 수 있고, 이 프로그램이 쓰는 만큼은 무료 한도 안에서 끝납니다.
- **🧪 열쇠 시험** 버튼으로 바로 확인할 수 있습니다.
- 영상 하나에 20~30초쯤 더 걸립니다. 잘 안 되면 예전처럼 파일 이름으로 그냥 올라갑니다.
- **쪽지(json)에 적은 제목과, 화면에서 손으로 고친 제목이 늘 먼저입니다.**

> 켜면 영상이 **본인의 구글 AI 스튜디오 계정으로** 한 번 올라갔다가 곧바로 지워집니다.
> 제목을 지으려면 구글이 영상을 봐야 하기 때문입니다. 기본은 꺼짐이고, 끄면 아무것도 올라가지 않습니다.
> 열쇠는 본인 것이고 이 컴퓨터에만 저장됩니다.

## 🐞 제목이 서로 다른데 중복영상이라고 뜨던 것

먼저 올린 제목을 **일부라도 품고 있으면** 같은 편으로 보던 것이 원인이었습니다.
「여당만 몰랐던 209일」 을 올린 뒤 「여당만 몰랐던 209일의 진실」 을 올리면
다른 영상인데도 중복으로 세워졌습니다.

이제는 **제목이 똑같을 때만** 세웁니다. 채널에 걸어 둔 제목 앞뒤 문구는
견주기 전에 떼어 내므로, 같은 편을 두 번 올리는 것은 그대로 막힙니다.
똑같은 파일을 다시 넣는 것도 예전처럼 파일 지문으로 잡습니다.

## 🐞 "127.0.0.1에서 연결을 거부했습니다" 가 계속 뜨던 것

다른 프로그램이 8777 번을 잠깐 쓰고 있으면 옆 번호로 비켜 갔는데,
**그 번호가 설정에 굳어** 다음부터도 8777 로는 들어갈 수 없었습니다.
안내문은 전부 8777 이라 화면을 영영 못 여는 상태가 됐습니다.
업데이트 직후에 특히 잘 생겼습니다 — 방금 꺼진 판이 자리를 놓기 전에
새 판이 켜지기 때문입니다.

- 비켜 간 번호를 **설정에 굳히지 않습니다.** 8777 이 비면 다음에 켤 때 돌아옵니다.
- 원하던 번호는 **곧바로 포기하지 않고** 잠깐 기다렸다 다시 잡습니다.
- 이미 돌고 있는 판을 **옆 번호까지 찾아봅니다.** 두 번째 판이 겹쳐 뜨지 않습니다.
- 비켜 갈 때 기록에 **실제 주소**를 남깁니다.

## 🗑 유튜브에서 지운 영상이 첫 화면에 빈 칸으로 남던 것

올린 지 3시간이 지났는데도 유튜브에 없으면 기록에서 뺍니다.
갓 올린 것은 아직 처리 중일 수 있어 「사라짐」 표시만 남깁니다.

## 🏷 의견 게시판에 진행 상태가 보입니다

보내 주신 의견이 지금 어디까지 왔는지 표로 보입니다 —
**🆕 접수 → 🔍 살펴보는 중 → 🔧 고침 · 배포 대기 → ✅ 완료.**
알려 주실 것이 있으면 **❓ 확인 필요** 가 붙습니다.
**✅ 완료** 는 고친 때가 아니라 **배포까지 끝나 실제로 받으실 수 있을 때** 붙습니다.
