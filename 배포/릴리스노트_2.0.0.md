# 가라사대 업로더 2.0.0

## 🚀 겉모습은 그대로, 안쪽을 통째로 새 방식으로 바꿨습니다

화면은 알아보시는 그대로입니다. 바뀐 것은 **로그인하는 방법, 영상이 올라가는 흐름, 돌아가는 방식**입니다.
옛 방식(폴더를 지켜보다가 파일이 보이면 바로 올림)은 없어졌고, 이제는 **영상을 골라 담고 → 확인하고 → 올립니다.**

## ✅ 먼저, 이미 쓰고 계신 분께

**등록해 둔 채널은 하나도 없어지지 않습니다.** 자동으로 2.0.0 이 되면 처음 켤 때 다음 순서로 옮깁니다.

1. 옛 설정·로그인 정보·올린 기록을 **날짜가 붙은 복사본 폴더**에 통째로 복사해 둡니다 (`백업/이행전_날짜_시각`).
2. 새 방식으로 **복사해서 옮깁니다.** 옛 파일은 지우거나 덮어쓰지 않고 그대로 둡니다 — 옛 버전으로 되돌려도 다시 돌아갑니다.
3. 옮긴 뒤 **하나씩 다시 확인합니다.** 옛 채널 수와 새 채널 수가 같은지, 채널마다 로그인 정보·채널 ID·폴더가 이어졌는지, 올린 기록(예약 포함)이 모두 있는지.
4. 하나라도 빠졌으면 **새 방식으로 올리지 않고 멈춥니다.** 문제 목록에 빨간 줄과 복사본 위치가 뜨고, 「다시 옮기기」를 누르면 이어서 다시 합니다.

이미 로그인해 둔 채널은 **다시 로그인하지 않아도 됩니다.** 옛 열쇠로 받은 로그인은 그 열쇠 그대로 계속 씁니다.
도중에 컴퓨터가 꺼져도 다음에 켤 때 이어서 끝냅니다. 몇 번을 돌려도 결과가 같고, 채널이나 기록이 두 벌로 늘지 않습니다.

> 로그인이 풀리거나 만료되어도 채널은 지워지지 않습니다. 채널 카드에 **「다시 연결 필요」** 라고만 표시됩니다.
> 채널을 빼거나 연결을 해제하는 것은 **직접 확인 창에서 누를 때만** 됩니다.

## 🔑 구글 로그인이 훨씬 쉬워졌습니다

- **구글 클라우드 프로젝트를 직접 만들 필요가 없습니다.** 로그인 열쇠가 프로그램에 들어 있습니다. **구글 로그인** 한 번이면 됩니다.
- 한 구글 계정에 채널이 여럿이면 로그인 창의 **계정 선택**에서 채널을 바꿔 가며 잇달아 연결할 수 있습니다. 같은 채널을 두 번 연결해도 한 자리로 합쳐집니다.
- TV·기기용 **코드 인증**(코드를 불러 주고 다른 기기에서 승인)도 됩니다.
- 권한은 **세 가지만** 받습니다: 영상 올리기 · 유튜브 읽기 · 영상 정보 고치기.
- 연결하자마자 채널 이름·배너·프로필 사진을 받아 오고 채널 자리를 만들어 둡니다.
- 내 열쇠를 쓰고 싶으면 채널마다 **전용 열쇠 파일**을 지정할 수 있습니다 (열쇠 파일을 화면에 끌어다 놓거나, 클라이언트 ID·비밀번호를 붙여넣기).

## 📤 올리는 흐름

폴더에 영상을 넣으면 화면에 카드로 나옵니다. **담기 → 올리기 확인 창 → 올리기.**

- 올리는 순간은 항상 사람이 누릅니다. 새로고침이나 뒤로가기, 북마크로는 올라가지 않습니다.
- 처음엔 **비공개**로 올리고, 30분 뒤 유튜브 심사 결과를 확인해 공개합니다. 공개 간격은 채널마다 지켜집니다.
- **쇼츠와 롱폼을 자동으로 가립니다.** 180초 이하의 세로·정사각 영상은 쇼츠, 그 밖은 롱폼이고, 하루 편수·공개 간격·예약 칸도 종류별로 따로 셉니다.
- 정한 시각에 올리는 **발사 대기**, 하루 한도를 넘으면 다음 날로 자동으로 밀기, 올린 뒤 원본 정리(옛 폴더로 옮기기 · 휴지통 · 그대로).
- 같은 영상을 두 번 올리지 않습니다 (파일 이름·제목·유튜브에 실제로 있는 영상까지 대조).
- 10분마다 심사를 확인하는 작업이 **따로** 돕니다 (화면을 닫아도): 맥은 로그인 때 자동 시작 두 개, 윈도우는 시작 프로그램과 작업 스케줄러.

## ✨ 새 기능

### 영상에 맞는 제목·설명·해시태그를 자동으로 (기본 켜짐)

문안(제목 파일·쪽지)이 없는 영상은 올리기 직전에 영상 내용과 **내 채널의 말투**(최근·잘된 영상)를 보고 제목·설명·해시태그를 지어 넣습니다.
쇼츠와 롱폼의 형식이 다르게 지어지고, 길이·글자 규칙을 통과한 것만 쓰입니다.

- 화면에서 직접 고친 것 > 쪽지 > 자동 > 파일 이름 순으로 쓰입니다.
- 열쇠는 **각자 자기 것**(구글 AI 스튜디오 무료 등급)을 넣습니다. 열쇠가 없으면 파일 이름이 제목이 되고 문제 목록에 안내가 뜹니다.
- 채널마다 설명 앞·뒤 글, 늘 넣을 해시태그, 말투 메모를 정할 수 있습니다.

### 영상마다 알맞은 쿠팡 파트너스 상품 링크

영상 소재에 맞는 상품을 골라 설명 끝에 1~3개 붙이고, 파트너스 고지문을 함께 넣습니다. 관련 상품이 없으면(뉴스·정치 등) 억지로 넣지 않습니다.

- 파트너스 계정은 **각자 자기 것**입니다 (수수료가 내 계정으로 들어갑니다).
- 채널마다 켜고 끄기·하위 ID 를 따로 정할 수 있고, 올리기 전에 어떤 링크가 붙는지 미리 봅니다. 사람이 직접 넣은 링크가 있으면 그것이 먼저입니다.
- 쿠팡이 안 되거나 한도에 닿아도 **올리기는 멈추지 않습니다.**

### 처음 켜면 열쇠 창이 한 번 뜹니다

AI 열쇠와 쿠팡 열쇠를 한 창에서 넣습니다. **이 컴퓨터에 이미 있는 열쇠를 찾아서** 가려서 보여 주고(`AIza…끝4자리`와 찾은 자리), 연결 시험을 통과한 것만 **「이걸로 쓰기」** 한 번으로 연결합니다. 찾기는 읽기만 하며 아무것도 바꾸거나 어디로 보내지 않습니다.
나중에 넣으려면 화면 위의 **「AI 연결」·「쿠팡 파트너스 연결」** 단추를 누르세요.

### 그 밖에

- **문제 목록**: 오류·작업불이행·경고를 등급별로 모아 보고, 고칠 수 있는 것은 단추로 고칩니다. 올리지 못한 영상은 파일별로 이유와 할 일이 나옵니다.
- **성적·기록 탭**: 날짜별·채널별 올린 편수, 영상별 조회, 채널 성적 카드, 끌어올릴 영상, 구독자 증감, 수확 진행.
- **명령줄**: 실행 파일 뒤에 `올려` `공개` `문제` `설정` `인증` 같은 한글 명령을 붙여 쓸 수 있습니다 (`도움말` 로 전체).
- **안전장치**: 올리기 잠금, 심야 금지·일시정지, 폴더와 채널 짝 검사, 문안 규격 검사.

## 🛠 알아 두실 것

- 옛 방식의 **「모든채널」 폴더와 「전체 업로드 대기」 칸은 없어졌습니다.** 같은 영상을 여러 채널에 올리려면 채널별 폴더로 옮겨 담으면 됩니다. 이행할 때 옛 「모든채널」 폴더에 기다리는 영상이 있으면 알려 드립니다 (옮기지는 않습니다).
- 옛 방식의 **첫 댓글 자동 달기·제목 자동 교체**는 새 로그인 방식으로는 권한을 받을 수 없어 빠졌습니다. 이행할 때 어떤 채널이 쓰고 있었는지 알려 드립니다.
- 폴더를 몇 초마다 훑으며 지켜보다가 바로 올리던 방식은 없어졌습니다. 영상을 채널 폴더에 넣으면 「감시 중」 탭의 영상 벽에 카드로 나오고, 올리는 것은 직접 누릅니다.
- 옛 자동 시작(맥 로그인 항목 · 윈도우 시작 프로그램)은 처음 켤 때 새 방식(작업 둘)으로 올립니다. 옛 파일은 지우지 않고 옆으로 치워 둡니다.
