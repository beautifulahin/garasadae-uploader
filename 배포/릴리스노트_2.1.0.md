# 가라사대 업로더 2.1.0

## 📷 쇼츠를 인스타그램 릴스·스레드에도 함께 올립니다 (선택 · 신청한 분만)

**유튜브에 올린 쇼츠가 공개되는 때에 맞춰, 같은 영상을 인스타그램 릴스와 스레드에도 자동으로 올릴 수 있습니다.**
쓰지 않으면 아무것도 달라지지 않습니다 (기본은 꺼짐).

- 설정 탭에 **📷 인스타그램·스레드** 칸이 생겼습니다. *인스타그램 연결* / *스레드 연결*을 누르고 로그인만 하면 됩니다. 비밀번호나 열쇠를 프로그램에 입력하지 않습니다.
- 채널마다 어디에 올릴지(인스타그램 · 스레드) 따로 켜고 끕니다.
- 문안은 유튜브 문안에서 만들어 줍니다 — 인스타그램은 제목 + 설명 + 해시태그, 스레드는 제목 + 짧은 설명입니다.
- 영상이 크거나(4K 등) 길이·화질 규격을 넘으면 **릴스·스레드용으로 자동으로 줄여서** 올립니다. 원본 파일은 그대로 둡니다. 줄이는 동안 화면에 「줄이는 중」이 보입니다.
- 올리다가 결과를 알 수 없게 되면 **같은 영상을 두 번 올리지 않도록** 다시 보내지 않고 멈춥니다.

### 쓰려면 먼저 신청해 주세요

이 기능은 **사용 신청을 하고 초대를 수락한 계정만** 연결됩니다.

1. **신청** — 인스타그램 아이디(스레드도 쓰면 함께)를 **beautifulahin@gmail.com** 으로 보내 주세요. 설정 탭의 *✉ 신청 메일 쓰기* 단추를 누르면 제목과 아이디 칸이 적힌 메일이 열립니다.
2. **초대 수락** — 인스타그램은 instagram.com › 설정 › 앱 및 웹사이트 › 「테스터 초대」, 스레드는 스레드 앱 › 설정 › 웹사이트 권한 › 초대에서 수락합니다.
3. **연결** — 설정 탭에서 *인스타그램 연결* / *스레드 연결*을 누릅니다.

> - 인스타그램은 **비즈니스 또는 크리에이터 계정**이어야 합니다 (인스타그램 앱에서 무료로 바꿀 수 있습니다).
> - 신청하지 않았거나 초대를 수락하지 않은 계정으로 로그인하면 연결되지 않고, 화면에 신청 방법과 수락하는 곳이 안내됩니다.
> - 로그인 때 토큰을 바꿔 주는 중계 서버를 잠깐 거칩니다. 5분 안에 지워지며 개인정보처리방침에 적혀 있습니다.
